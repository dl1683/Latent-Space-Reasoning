- What question still protects against an overclaim?
- What question still names an uncertainty no other question names?
- What question still bridges two research lines that would otherwise drift apart?
- What question still forces evidence rather than language?

- What question asks about evidence and incentives at the same time?
- What question asks about memory and maintenance at the same time?

- What two questions always fail under the same counterexample?
- What two questions only differ by metaphor?
- What two questions only differ by domain label?

## Which Question Should Be Demoted?

- What question is still interesting but no longer controls a near decision?
- What question is still historically important but no longer action-guiding?
- What question is still plausible but no longer evidence-backed enough to lead?
- What question is still useful as context but dangerous as authority?
- What question should move from frontier to archive?
- What question should move from claim-bearing to provenance-bearing?
- What question should be read only after stricter questions are answered?

## Which Question Should Be Archived?

- What question was once live but is now resolved enough to stop steering work?
- What question led to a dead end that future agents might rediscover?
- What question records a falsifier that should remain searchable?
- What question preserves a negative result that prevents repeated waste?
- What question preserves the path by which an overclaim was killed?
- What question should be available for memory but unavailable for promotion?
- What archive marker would prevent a retired question from returning as a fresh insight?

## Which Question Should Be Deleted?

- What question has no decision, evidence, provenance, or future search value?
- What question is only a vibe?
- What question is only a slogan?
- What question is only a paraphrase of a sharper question?
- What question creates false depth by adding words?
- What question makes the corpus harder to use without preserving any unique uncertainty?
- What question would improve the meditation system most by disappearing?

## Which Question Should Be Promoted?

- What question has become more important after later study?
- What question now connects to multiple independent sources?
- What question now has a clearer falsifier than when it was written?
- What question now controls a build, gate, paper, or public claim?
- What question now exposes a portfolio-wide anti-pattern?
- What question now deserves to become a frontier question?
- What question now deserves to become a public method question?

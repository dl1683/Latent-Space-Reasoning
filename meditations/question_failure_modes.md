- What question would sound deep while controlling no decision?

- What question would look recursive while only restating itself?
- What question would perform humility while protecting a preferred answer?
- What question would let the system avoid building forever?
- What question would let the system build too soon while claiming it had meditated?
- What question would convert uncertainty into aesthetic fog?

- What metric would reward question length rather than question precision?
- What metric would reward novelty rather than contact with the bottleneck?
- What metric would reward elegance rather than falsifiability?
- What metric would reward coverage rather than priority?
- What metric would reward question-only form while allowing answer-shaped assumptions to hide inside questions?
- What metric would reward file cleanliness while removing the uncertainty that made the file useful?

- What useful answer would be rejected because it looked too final?
- What necessary build would be delayed because action looked like insufficient meditation?
- What clear evidence would be attacked because it threatened a favored uncertainty?
- What productive simplification would be treated as overcompression?
- What trustworthy claim would be treated as suspicious merely because trust is dangerous?
- What future agent would be punished for resolving a question rather than generating more?

- What term will drift fastest?
- What source will age fastest?
- What artifact will become authoritative after it stops being current?
- What question will survive only because no one pays the cost to delete it?
- What maintenance routine will become ritual rather than repair?

## How Could The Question System Overfit?

- What question is too tuned to the current repo surface?

- What question is too tuned to the current agent's vocabulary?
- What question is too tuned to the current user's frustration?

- What question is so broad that every answer looks relevant?
- What question is so philosophical that no build could ever test it?
- What question is so abstract that it hides the named artifact it should inspect?
- What question is so cautious that it cannot produce a falsifier?
- What question is so meta that it never touches the system?
- What question is so safe that it cannot discover anything?

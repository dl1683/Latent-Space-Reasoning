# Question Affect And Motivation?

## What Makes A Question Matter?
- What signal tells the system that one uncertainty matters before it has finished proving that it matters?
- What is the difference between a question that is true, a question that is useful, a question that is urgent, and a question that the system cares about?
- What would make a question feel important while having low expected information value?
- What would make a question feel boring while controlling a high-leverage decision?
- What hidden affective marker tags some files as exciting, dangerous, stale, shameful, or sacred before explicit reasoning begins?
- What would a reasoning system do differently if it could inspect the felt priority that preceded the search?
- What question asks whether the corpus is selecting for what matters or for what feels like it matters?
- What deeper question is needed before importance can be distinguished from arousal?

## What Is Relevance Before Reasoning?
- What pre-filter chooses which facts become candidates for deliberate thought?
- What emotional or motivational signal narrows the frame problem before the agent searches the repo?
- What does fear make relevant that calm analysis might miss?
- What does curiosity make relevant that deadline pressure might suppress?
- What does boredom make relevant by making the current path feel exhausted?
- What does frustration make relevant by marking repeated failure as intolerable?
- What does care make relevant by preserving attention on low-novelty work that still matters?
- What question asks whether relevance is being computed by evidence, affect, habit, user urgency, or artifact salience?

## What Is A Somatic Marker For A Repo?

- What prior failure should create a negative marker before the system repeats the same pattern under a new name?
- What prior success should create a positive marker without becoming superstition?
- What trace, benchmark, commit, or user correction should be allowed to bias future question selection before full deliberation?
- What marker should attach to uncommitted work, unshipped finished work, stale public claims, generous metrics, and overbuilt prototypes?

- What marker should decay if it is never refreshed by evidence?
- What question asks whether memory is inert unless it changes future felt priority?

## What Is Curiosity?

- What uncertainty offers compression progress rather than random surprise?

## What Is Care?

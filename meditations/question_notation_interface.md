# Question Notation And Interface?

## What Does The Medium Make Thinkable?
- What ideas become easy because the project thinks in markdown files, headings, bullets, git diffs, benchmark tables, prompts, traces, and terminal output?
- What ideas become hard because the current medium does not naturally show time, causality, uncertainty, dependency, ownership, provenance, or opportunity cost?
- What would this reasoning system notice if its primary notation were a graph, timeline, proof object, dashboard, simulation, or typed schema instead of prose?
- What does question-only markdown reveal that ordinary planning documents hide?
- What does question-only markdown hide that implementation, benchmark traces, user workflows, or source maps would reveal?
- What cognitive load is being offloaded into file structure, and what cognitive load is being pushed back onto future readers?
- What structure is currently invisible because there is no symbol for it?
- What question asks whether the medium is shaping the paradigm more than the paradigm is shaping the medium?

## What Is The Notation Doing?
- What work is performed by a heading before any bullet underneath it is read?
- What work is performed by a filename before the file becomes evidence, speculation, memory, or authority?
- What work is performed by a question mark when the sentence still contains a hidden claim?
- What work is performed by repeated terms like grounding, institution, maintenance, calibration, selection, and power?
- What does the current notation make cheap to add and expensive to revise?
- What does the current notation make easy to scan but hard to compare?
- What does the current notation compress, and what does it over-expand?
- What would a better notation make impossible to ignore?

## What Is The Interface Doing?
- What does the terminal interface make the agent more likely to inspect?
- What does the chat interface make the agent more likely to over-explain?
- What does the file tree make the agent treat as discrete even when the real structure is relational?
- What does git status make visible about work that ordinary prose would hide?
- What does search make retrievable while leaving unsearched absences invisible?
- What does a markdown corpus make durable before it has earned durability?
- What does the absence of a visual map make harder to reason about?
- What interface would make the next question's dependencies visible before the next question is written?

## What Is External Memory?
- What should be remembered in the file system because biological or conversational memory is too fragile?
- What should not be remembered in the file system because durable storage would give premature authority to a weak thought?
- What is the difference between external memory, external clutter, external governance, and external temptation?
- What memory should remain inspectable by future agents rather than hidden in the current conversation?
- What memory should remain private because it is not ready to guide future work?
- What external memory format preserves reasoning lineage rather than only final wording?
- What should a question remember about why it was born?
- What should a question forget so it can remain usable?

## What Is A Prompt As Notation?
- What does the prompt language make easy to specify and hard to verify?
- What ambiguity does a natural-language prompt preserve that a formal schema would destroy?
- What ambiguity does a natural-language prompt hide that a formal schema would force into the open?
- What would happen if question generation were expressed as a typed program rather than an instruction?
- What would happen if each question had required fields for uncertainty type, evidence source, decision controlled, failure mode, and retirement condition?
- What does the current prompt reward the agent for noticing?
- What does the current prompt let the agent avoid noticing?
- What question asks whether the prompt is a programming language for attention?

## What Is A Type System For Questions?
- What impossible question states should the corpus refuse to compile?
- What type should distinguish speculation, evidence request, mechanism probe, calibration check, governance concern, shipping gate, and public-claim risk?
- What type should distinguish a live question from an archived question, a source-derived question from an invented question, and a decision-controlling question from an exploratory question?
- What type error occurs when a meditation question is used as implementation authority?
- What type error occurs when a benchmark number is used as a philosophical answer?
- What type error occurs when a public README claim is supported only by private reflection?
- What type system would make hidden side effects of questions visible?
- What would question inference infer automatically, and what should never be inferred?

## What Is A Table For Questions?
- What would become visible if every question were placed in a table with columns for source, uncertainty, decision, risk, evidence, owner, freshness, and next mutation?
- What would be lost if rich recursive questions were flattened into table rows?
- Which comparisons are currently too hard because related questions live in separate prose files?
- Which redundancies would become obvious if questions were sortable?
- Which false equivalences would become more likely if questions were forced into uniform columns?
- What question deserves a matrix rather than a paragraph?
- What question deserves a timeline rather than a list?
- What question deserves a dependency graph rather than a file?

## What Is A Diagram For Questions?
- What relationship between questions is too spatial to express cleanly in bullets?
- What hidden loop would become obvious if question dependencies were drawn?
- What bottleneck would become obvious if question influence were drawn as flow?
- What hierarchy would become obvious if question categories were drawn by attention share?
- What dead end would become obvious if abandoned question paths were drawn?
- What ambiguity would a diagram falsely resolve by forcing a single layout?
- What diagram would invite premature confidence because it looks complete?
- What question asks whether visual clarity is truth or just another notation bias?

## What Is A Proof Object For Questions?
- What would it mean for a question to carry a proof object showing why it follows from prior questions and sources?
- What inference step between two questions is currently trusted only because the prose sounds continuous?
- What assumptions would need to be explicit for a question lineage to be checkable?
- What claim is smuggled into the transition from one question to the next?
- What would a verifier check about a question besides whether it ends in a question mark?
- What parts of question quality cannot be formalized without destroying their usefulness?
- What proof obligation should be attached before a question controls a build or public claim?
- What would a failed proof object teach about the corpus?

## What Is An Instrument?
- What instrument would let the project measure whether questions improve later reasoning rather than merely increase later text?
- What instrument would reveal when a question made a future agent search better?
- What instrument would reveal when a question caused a future agent to avoid premature implementation?
- What instrument would reveal when a question delayed necessary action?
- What instrument would reveal whether a question changed source selection, benchmark interpretation, or repo cleanup?
- What instrument would distinguish causal impact from narrative fit?
- What instrument should exist before the corpus claims that meditation improved reasoning?
- What question asks whether the system is over-studied and under-instrumented?

## What Is Search As Interface?
- What can `rg` find that conceptual reading misses?
- What can conceptual reading find that `rg` cannot search for?
- What terms does the corpus overuse enough to make search falsely reassuring?
- What absences are invisible because there is no agreed keyword for them?
- What would semantic search retrieve that lexical search misses?
- What would lexical search protect against that semantic search might smooth away?
- What query should every new question suggest for future verification?
- What question asks whether search has become the project’s memory rather than a tool for interrogating memory?

## What Is The Language Boundary?
- What part of the reasoning problem can be said in prose?
- What part must be shown in tests, traces, diagrams, interfaces, embodied workflows, or public submissions?
- What tacit judgment is being converted into language with too much loss?
- What embodied user workflow is being described but not experienced?
- What meaning depends on being the person who will use, maintain, cite, or trust the result?
- What would be misunderstood by an agent that has the words but not the form of life around the work?
- What should the question corpus stop trying to say and instead force the system to observe?
- What question asks whether language is currently the bottleneck rather than the solution?

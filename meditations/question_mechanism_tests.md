# Question Mechanism Tests?

## When Is A Pattern More Than An Analogy?

- What prediction does the pattern make that a loose analogy would not make?
- What variable must correspond across domains for the pattern to be real?
- What operation must preserve structure across domains?
- What counterexample would break the claimed mechanism?
- What would transfer if the mechanism is real?
- What would fail to transfer if the resemblance is only verbal?
- What domain should be excluded because the mapping is too weak?

## What Is The Shared Object?

- What object exists in every domain being compared?
- What relation defines that object rather than its label?
- What measurement exposes that object without importing the metaphor?
- What transformation acts on that object in each domain?
- What invariant survives the transformation?
- What boundary separates the shared object from domain-specific decoration?
- What would show that two domains share vocabulary but not object structure?

## What Is The Shared Failure Mode?

- What failure recurs across domains with the same causal shape?
- What local metric beats a global metric in every instance?
- What maintenance process fails in the same order?
- What trust mechanism is attacked through the same opening?
- What memory process loses provenance in the same way?
- What compression process hides the same decision-relevant state?
- What would show that similar failures have different causes?

## What Is The Shared Intervention?

- What intervention improves each domain for the same structural reason?
- What intervention should not work if the analogy is false?
- What intervention changes a local metric but not the integration metric?
- What intervention changes state quality before output quality?
- What intervention changes verification rather than generation?
- What intervention changes memory governance rather than retrieval volume?
- What intervention would be cheap enough to test before promoting the mechanism?

## What Is The Shared Falsifier?

- What observation would falsify the mechanism in one domain?
- What observation would falsify it across domains?
- What observation would preserve the local result while killing the universal claim?
- What observation would show that the constant is coincidental?
- What observation would show that the threshold is a measurement artifact?
- What observation would show that the mechanism only applies inside one architecture family?
- What observation would force the pattern back into the analogy archive?

## What Is The Assembly Index Of The Mechanism?

- How many independent construction paths lead to the same mechanism?
- Which paths share data, tools, incentives, or authors?
- Which paths are genuinely independent?
- Which path is the weakest link?
- Which path was produced by falsifying an older claim?
- Which path would still stand if the prettiest analogy disappeared?
- What copy number would show selection rather than rhetorical reuse?

## What Does The Mechanism Predict Before The Result?

- What can the mechanism forecast before a score is known?
- What can it forecast before a repair is run?
- What can it forecast before a benchmark is selected?
- What can it forecast before a public claim is written?
- What can it forecast about where scaling should break?
- What can it forecast about where transfer should fail?
- What can it forecast about which evidence should decay fastest?

## What Does The Mechanism Explain After Failure?

- What failure would the mechanism make less surprising?
- What negative result would become stronger because the mechanism predicted it?
- What overclaim would the mechanism have warned against?
- What dead end would the mechanism keep dead?
- What abandoned data would the mechanism make worth reanalyzing?
- What anomaly would the mechanism preserve instead of explaining away?
- What failed analogy would the mechanism help retire?

## What Is The Mechanism's Domain Of Validity?

- Where does the mechanism apply?
- Where does the mechanism stop applying?
- What scale transition changes the mechanism?
- What architecture transition changes the mechanism?
- What timescale transition changes the mechanism?
- What evidence-quality transition changes the mechanism?
- What cost transition changes the mechanism from useful to misleading?

## What Is The Mechanism's Strict Metric?

- What is the generous metric that would make the mechanism look better than it is?
- What is the strict metric that would decide whether the mechanism survives?
- What integration metric must improve?
- What local metric is allowed to improve without promotion?
- What metric split would reveal that the mechanism is only local?
- What metric split would reveal that state improved before output?
- What metric split would reveal that the mechanism is useful but not universal?

## What Is The Mechanism's Cheapest Probe?

- What existing artifact can test the mechanism first?
- What abandoned analysis can test it before new work?
- What negative result can test it before positive evidence?
- What cross-domain comparison can test it without building?
- What cheap counterfactual can test it before GPU spend?
- What source audit can test it before modeling?
- What one-row probe would be enough to decide whether deeper work is justified?

## What Is The Mechanism's Public Claim Boundary?

- What can be claimed if the mechanism holds only locally?
- What can be claimed if it holds across two domains?
- What can be claimed if it holds across independent substrates?
- What cannot be claimed until the falsifier has been attempted?
- What cannot be claimed until strict metrics lead?
- What cannot be claimed until the analogy archive has been searched for dead matches?
- What caveat must travel with the mechanism every time it is named?

## What Question Should Every Cross-Domain Claim Answer?

- What is the shared object?
- What is the shared operation?
- What is the shared invariant?
- What is the shared failure mode?
- What is the shared intervention?
- What is the shared falsifier?
- What would make this mechanism less beautiful but more true?

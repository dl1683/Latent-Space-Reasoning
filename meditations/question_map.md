# Question Map?

## What Is This Map Trying To Preserve?

- Which questions in the ladder define the object being studied?
- Which questions define the boundary of the system that is allowed to reason?
- Which questions define the maintenance process that keeps inquiry from decaying?
- Which questions define the evidence contract that prevents a paradigm claim from outrunning proof?
- Which questions define the search process that makes later questions better than earlier questions?

- What must be true before a final string can be treated as only one surface of a deeper reasoning object?

- What deeper question turns a repair decision into a costed intervention rather than a success story?
- What deeper question turns a proof object into a living claim ledger rather than a report format?
- What deeper question asks whether the true object is the lifecycle by which claims are born, repaired, narrowed, retired, and replayed?

## Which Questions Define The Boundary Of The Reasoner?

- Where is the Markov blanket of this reasoning system?
- What belongs inside the system because it changes future reasoning state?
- What belongs outside the system because it is only an observation, constraint, or perturbation?
- What boundary would separate the model from the institution around the model?
- What boundary would separate a reasoning trace from the archive that makes the trace meaningful?
- What boundary would separate a local repair from the global research organism it can harm?
- What boundary would make the phrase "the model reasoned" too small to be accurate?

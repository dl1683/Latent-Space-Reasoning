## Rigor and gate vocabulary

- **PROVED:** accepted only when the proof is present and a fresh independent Codex
  reviewer has attacked it and failed. No new statement in this round has that label.
- **EMPIRICAL:** a source, measurement, or execution fact, limited to the stated
  evidence boundary.
- **CONJECTURE:** a precise mathematical target not yet proved.
- **HEURISTIC:** a design judgment, proposed reduction, or unreviewed inference.
- **SPECULATION:** a candidate payoff or direction without a cleared theorem route.

The Stage-A tokens from `research/GATE2_BRIEF.md` remain controlling:

- **TASK-MISMATCH-CLEAR:** the identical finite useful task leaves a nonempty mismatch
  after implicit-state, oracle, direct-task, algorithm, hardware, location, and I/O
  symmetry, and the smallest allegedly mispriced primitive is named.
- **ABSORBED:** any one of those controls, an established model, or matched hardware
  closes the mismatch.
- **VOID:** the task, stakeholder, physical boundary, output metric, or competitor is
  changed during adjudication, so evidence no longer answers the registered claim.

For founding status, Stage A is necessary but not sufficient. **OCCUPIED-KILL** means
the task comparison may support an architecture theorem, but its model story is
already present in the literature. **REGISTERED-TO-ARTILLERY** permits only the
pre-theorem attacks in this document. It is not a success token and not a model
selection.

proves an asymptotic impossibility. Both make a propagation-only upper bound an
unacceptable premise.

## 3. Primary card: post-fabrication programmable wave operator

### 3.1 Registration status and the correction to the supervisor's lean

**SPECULATION — REGISTERED-TO-ARTILLERY.** This is the strongest live *search card*
because it is constructed against the accumulated kill map. That fact does not yet
make it the strongest live *founding model*. Passing necessary anti-confound controls
is not evidence that a mismatch exists.

Post-fabrication arrival blocks **instance-specific fabrication**, not all nonuniform
advice. The size-specific fabric, mode basis, calibration map, control compiler, and
stored correction table can still carry nonuniform information. Likewise, requiring
an optical field at the output can make the task useful while still privileging the
wave substrate at the interface. Both are first-order attacks below.

### 3.2 Frozen calibration family

The first card is deliberately narrower than “programmable linear algebra.” Let
\(N\) coherent time/frequency-bin modes occupy registered terminals and let \(F_N\)
be the unitary \(N\)-point DFT. For a declared phase precision \(b\), define

\[
\Theta_{N,b}=\{0,1,\ldots,2^b-1\}^N,
\qquad
A_\theta=F_N^*\operatorname{diag}
\left(e^{2\pi i\theta_j/2^b}\right)_{j=1}^N F_N.
\]

**DEFINITION — HEURISTIC.** The registered calibration family is

\[
\mathcal A^{\rm circ}_{N,b}=\{A_\theta:\theta\in\Theta_{N,b}\}.
\]

It is a finite family of passive unitary circulant coherent filters. The program has
exactly \(Nb\) bits; arbitrary real phase masks and arbitrary dense \(N\times N\)
matrices are not admitted. This family is chosen because a fixed 4f-style
Fourier-domain pulse shaper with a programmable spectral phase mask is a concrete
candidate constructor, while an electronic fabric has the
FFT–diagonal–inverse-FFT route. The family is a calibration target, not a claim that
this will be the final useful family.

**VOID rule.** Replacing this family after seeing which architecture wins is VOID for
this registration. A new family requires a new card and new tokens.

### 3.3 Temporal order, task, and stakeholder

For each \(N\), freeze a public finite task-parameter tuple
\(\pi_N=(b,b_x,Q,\epsilon,\delta)\) before fabrication:

1. A uniform constructor receives \(1^N\) and the finite encoding of \(\pi_N\), then
   fabricates one fixed wave fabric \(W_N\) and one fixed comparator fabric \(E_N\).
   Their size-\(N\) descriptions, fabrication, basis choice, static calibration,
   area/volume, control, and retained state are charged. Neither constructor sees
   \(\theta\) or any \(x^{(k)}\).
2. After both fabrics are fixed, the \(Nb\)-bit program \(\theta\) arrives. Both
   fabrics may store it and amortize its loading over exactly the precommitted \(Q\)
   inputs—never over an unstated infinite future.
3. A batch of \(Q\) finite digital complex vectors
   \(x^{(1)},\ldots,x^{(Q)}\) from a predeclared \(b_x\)-bit codebook, each with
   \(\|x^{(k)}\|_2\leq1\), arrives. Input encoding/loading is charged on both sides.
4. For each input, the required output is a phase-referenced coherent field
   \(y^{(k)}\) on the same \(N\) named modes satisfying

   \[
   \Pr\!\left[
   \|y^{(k)}-A_\theta x^{(k)}\|_2\leq\epsilon
   \text{ for all }k\leq Q
   \right]\geq1-\delta.
   \]

   Global phase is not silently quotiented out; if the stakeholder does not carry a
   phase reference, the task must be re-registered with the correct quotient.
5. The field is delivered at a registered optical boundary to the calibration channel
   \(C_\theta=A_\theta^*\). The end-to-end stakeholder loss is
   \(\|C_\theta y^{(k)}-x^{(k)}\|_2\), which equals the registered field error because
   \(A_\theta\) is unitary. Neither competitor may substitute an unmaterialized array
   for the emitted field, but either may use a different algorithm to achieve this
   end-to-end loss.

**Named provisional stakeholder — HEURISTIC.** The stakeholder is an **adaptive
coherent optical OFDM transmitter/precompensator**. A channel estimate selects
\(\theta\) after the transmitter is built; the programmed unitary precompensator must
emit all \(N\) coherent time/frequency-bin modes into the link. Iteration 6 must verify that
this stakeholder really needs the declared coherent field and cannot replace it by
decoded bits, a few modes, intensity only, or a direct symbol decision. Until that
check passes, stakeholder usefulness is a conjecture.

**Direct-task control.** The end-to-end received-symbol loss and the full-field
contract must both be reported. If an electronic or hybrid transmitter attains the
stakeholder loss without materializing the registered intermediate field, the field
contract is an artificial strengthening and the card is **ABSORBED**. “The next stage
expects optics” is not by itself a computational separation.

### 3.4 Symmetric freedoms and charged resources

Both sides receive the same program and input bits at the same time, may retain warm
state, precompute any \(\theta\)-independent data, choose any uniform algorithm, use
their full declared parallel fabric, store \(\theta\), pipeline the \(Q\) inputs, and
return only the stakeholder-required output. Both pay for:

- uniform design and fabrication of the size-\(N\) fabric;
- \(Nb\) program bits, program decoding, loading, verification, reset, and the exact
  \(Q\)-use amortization schedule;
- calibration acquisition, calibration-table size, calibration compilation, drift
  correction, refresh, thermal/control energy, and failure recovery;
- input modulation or conversion, output emission/coupling, phase reference,
  detector/control paths used for feedback, and physical placement of all terminals;
- area, volume, aperture, wavelength, supported modes, path length, latency,
  throughput, fanout, wiring/routing, memory, and control bandwidth;
- phase/amplitude precision, dynamic range, photons/SNR, noise, error norm,
  confidence, and repetitions; and
- operational energy and peak power, not a unit-cost “propagation” or “FFT.”

The comparator set is fixed before results:

1. FFT ASIC/FPGA and near-memory electronic fabrics;
2. multilayer/3-D VLSI and bounded-bandwidth electronic networks;
3. analog electronic and in-memory linear fabrics with matched converters;
4. universal MZI meshes, programmable 4f/SLM processors, multi-plane light
   conversion, and other reconfigurable photonic networks; and
5. hybrid electronic–photonic systems and the direct downstream-task algorithm.

The reconfigurable-photonic check is not optional. It is both an occupation boundary
and a possible second wave constructor, not automatically a member of the electronic
CANNOT class. If an established programmable-photonics model already captures the
same task and resource story, excluding that work would manufacture novelty.
Conversely, two independently constructed wave implementations with polynomially
equivalent ledgers could later support a robustness theorem—but only after the
occupation search clears a strict theorem delta.

### 3.5 Allegedly mispriced primitive

**CONJECTURE.** If Stage A clears, the residue is not “a lens does an FFT instantly.”
It is **finite-capacity coherent interference and transport across \(N\) modes
through a post-programmed passive wave volume**, with only \(Nb\) instance bits loaded
and a phase-referenced field delivered downstream. The candidate electronic CANNOT
would have to price the same approximate multimode information transfer through
bounded electronic cuts plus the required optical emission boundary.

This primitive is not identifiable until the program, calibration, I/O, and optical
capacity bills leave a nonempty Pareto region. Until then it is only a conjectural
description of where a mismatch might live.

### 3.6 Pre-theorem artillery obligations

Iterations 6–8 must close all of the following before any CAN/CANNOT proof unit is
registered:

1. **Task and stakeholder closure.** Verify the coherent-transmitter use case, freeze
   the downstream loss and phase quotient, and run direct-task substitution.
2. **Uniformity closure.** Give uniform constructors for both fabrics and a uniform
   program-to-controls compiler. Size-specific calibration tables are charged advice;
   \(\theta\)-specific calibration before program arrival is forbidden.
3. **SLM/control attack.** Price pixel addressing, calibration acquisition, phase
   precision, refresh/drift, control bandwidth, and the conversion from the \(Nb\)
   program to physical settings. A nominal SLM write is not one step.
4. **Operator-loading attack.** Compare total program load and reset costs at the
   declared \(Q\). If loading is the lower bound on both sides, no transform-speed
   claim survives.
5. **Precision absorption attack.** Match the same normalized codebook,
   \(\ell_2\)-error, failure event, phase reference, photons/SNR, and dynamic range.
   Exact finite-ring word bounds may not proxy for this task.
6. **Finite optical upper audit.** Account for aperture, mode density, wavelength,
   path length, propagation time, photons, loss, phase stability, input modulation,
   output coupling, control, and calibration. No DFT or propagation primitive is
   assumed unit cost.
7. **Lower-bound feasibility and transfer screen.** Test whether robust cut/rank or
   mode-capacity technology lower-bounds this whole operator family and its downstream
   quotient. A DFT-only exact-word lemma fails the screen.
8. **Reconfigurable baseline closure.** Compare the best electronic, analog,
   reconfigurable-photonic, and hybrid implementations under the exact same boundary.
9. **Dedicated occupation search.** Read primary theory for programmable photonics,
   universal/reconfigurable optical processors, photonic FPGAs, field-programmable
   analog arrays, programmable diffractive/4f systems, MZI meshes, multi-plane light
   conversion, and relevant communication/VLSI lower bounds. Search snippets and
   engineering surveys do not clear novelty.
10. **Strict-delta statement.** State what theorem would remain beyond an accelerator
    benchmark, programmable-photonics model, VLSIO refinement, or ordinary circuit
    lower bound. If no such sentence survives, issue **OCCUPIED-KILL**.

### 3.7 CAN, CANNOT, robustness, fair-baseline, and infinity-leak targets

- **CAN — CONJECTURE.** A uniformly constructed finite 4f/programmable-mask device
  implements every \(A_\theta\in\mathcal A^{\rm circ}_{N,b}\) at a declared
  area–volume–time–energy–error–programming point including all preparation and
  delivery costs.
- **CANNOT — CONJECTURE.** A predeclared bounded-bandwidth electronic architecture
  class with the same program/input arrival and physical output terminals cannot
  attain a specified region of that same Pareto frontier. The theorem may be
  architecture-specific; it cannot be advertised as a universal digital lower bound.
- **Robustness — CONJECTURE.** Equivalent finite phase encodings, constant-factor
  changes of norm/error, bounded fabrication perturbations, and at least two genuine
  programmable-wave constructors preserve the resource class up to polynomial
  overhead. One lucky optical layout is an architecture result, not a model.
- **Fair baseline — HEURISTIC obligation.** Match implicit state, direct-task
  algorithms, parallelism, physical endpoints, converters, program reuse, and the
  reconfigurable/hybrid closure above.
- **Infinity-leak target — HEURISTIC obligation.** Seal arbitrary real controls,
  per-size/per-instance advice, unbounded mode count, unit-time propagation,
  infinite amortization, unpriced photons/phase reference, calibration oracles, and
  unmaterialized output.

### 3.8 One-strike conditions

Any one established condition below returns **ABSORBED** or **OCCUPIED-KILL** and ends
founding work on this card:

1. the stakeholder consumes only intensity, \(k\ll N\) modes, decoded bits, or a
   direct decision that removes the all-mode coherent contract;
2. the physical output requirement is the only reason electronics pays more, with no
   task-independent computational mismatch after matched endpoints;
3. the uniform constructor or control compiler needs a size- or instance-specific
   calibration/advice object whose charged construction matches the hard work;
4. program load, calibration, refresh, or reset matches or exceeds the alleged
   electronic lower-bound frontier at every declared \(Q\);
5. finite precision, photon count, phase stability, aperture, or path length closes
   the candidate optical upper;
6. a reconfigurable electronic, analog, or hybrid network matches the frontier under
   the same contract; an established reconfigurable-photonic model already contains
   the same CAN/cost story with no strict delta; or the comparison survives only by
   excluding the operation used in the wave upper;
7. no same-norm, same-codebook, same-failure electronic lower-bound route survives
   direct-task and output-quotient controls;
8. the registered structured family has a matched FFT/sparse-network implementation
   at every resource point, while any attempted dense-family rescue incurs
   \(\Omega(N^2)\) program load;
9. the dedicated source search finds the model/cost pair already present, leaving
   only device constants or a modern physical audit; or
10. the claimed upper still treats wave propagation, a Fourier transform, a mode, an
    SLM write, or a calibration as an unpriced primitive.

Changing the family, stakeholder, reuse schedule, approximation norm, downstream
boundary, or competitor after a strike is **VOID**, not a rescue. Only if all strikes
fail, the occupation search leaves a strict delta, and the exact residual primitive
is named may the card receive **TASK-MISMATCH-CLEAR** and return to a design gate for
theorem registration.

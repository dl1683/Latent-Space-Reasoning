# Repository map

```
README.md              start here
AGENTS.md              project rules (mission, rigor labels, scope)
docs/                  synthesis layer: read these to understand the project
  STATUS.md            where we are, the one blocker, open items
  RESULTS.md           every established result, scoped and labelled
  ATTEMPTS.md          every direction tried and why it ended
  DECISIONS.md         direction-setting decisions
  LESSONS.md           what the record teaches
  CLAIMS_LEDGER.md     older canonical claim index (detailed rows)
  FILE_MAP.md          old path -> new path for every moved file
research/              the substance, grouped by line of work
  july-program/        2026-07 model search, ACDFT, terminal gates
  erasure/             2026-10 erasure and statistical-context line
  access-dials/        ADAPTIVE, RECALL, CAT, delta tests, question reports
  endurance/           2026-10-04 endurance-limited storage line
  decisions/           converged steering decisions
  (each line has theory/ = definitions, candidates, proofs, protocols
                 and reviews/ = review and gate verdicts)
experiments/           code, ledger.jsonl, EXPERIMENTS.md (see its README)
results/               raw outputs and receipts (see its README)
literature/            papers (PDF), bibliography and source-comparison notes
archive/               provenance: review prompts, dialogue rounds, old logs
  history/             chronological logs and superseded status documents
  process/             review packets and per-round advisor/architect transcripts
```

Reading order for a newcomer: `README.md`, `docs/STATUS.md`, `docs/RESULTS.md`,
`docs/ATTEMPTS.md`, then the `theory/` file named in the result you care about.
File names are unchanged from the original flat layout and are unique, so a name
alone finds the file.

# Shared-carrier near-algebra v1 (unit carrier_near_algebra_v1)

Distance from claim: 1. Origin: 2026-10-03 meditation (Droid default model + Stateful Codex gpt-5.6-sol independently proposed the shared low-rank carrier; Antigravity agreed on the kill rules). Closest prior art (targeted, not systematic): Sherman-Morrison-Woodbury, Feshbach-Schur / impurity T-matrices, Dyson-Volterra, minimal state-space realisation / Hankel rank, Krylov model reduction. Under EXACT invariance the construction is classical by construction (both reviewers); the exact case is a POSITIVE CONTROL only. The unit tests the one non-classical feature: APPROXIMATE invariance with automatic carrier discovery from training operators and an a-priori computed leakage certificate surviving deep composition.
Headline if it passes: "A laptop replaced a chain of million-variable operators with arithmetic on a tiny interaction core and proved the full-state error." Verdict today: CONJECTURE / WEAK.

## PRE-REGISTRATION
Stage 1 (synthetic, CPU). Base A0 = hypercube walk (Hamming algebra, WHT-diagonal, eigenvalue by weight), n = 2^m, m in {8, 12, 16}. Step X_t = A0 + U C_t V^T + eps G_t, where U = V (symmetric case), r defect vectors ("site defects", r = 2), C_t random r x r of norm <= 1, G_t sparse symmetric perturbation of certified norm <= 1 that breaks the carrier (eps in {0, 1e-6, 1e-4}). Carrier discovery: Q = orthonormal basis of the A0-orbit of training defect vectors (16 training defect placements, SVD threshold 1e-10, scale preserved); held-out: 16 new defect placements/strengths. Depths L in {8, 16, 64}; query counts Q_n in {1, 100, 1000}. Output contract: action on a state vector, relative l2 error <= tau in {1e-3, 1e-6}, certificate computed from norms before comparing with truth (leakage recursion: leak_L <= leak_{L-1}*|A0| + |C|*|carrier mismatch| + eps ...; exact form written in the code docstring and fixed before the first run).
Comparators (same contract, all CPU, single-threaded timing, best-of-5): (S1) sequential WHT-diagonal step + low-rank apply; (S2) WHT with the same reduced active space and Woodbury/T-matrix style update (the matched specialist); (S3) first-order Frechet application.
Controls: positive (eps = 0, defects inside the discovered carrier): zero leakage, descriptor exact to float; negative (carrier discovered from unrelated random vectors): carrier dimension saturates / leakage certificate large.
H0 (boring): the descriptor equals the matched specialist S2 in lifecycle cost within 10% and the leakage certificate is >20x the true error once eps > 0.
H1: with eps > 0 the held-out carrier dimension stays <= 4(m+1) independent of depth, certificate <= 20x true error where true error > 10 x float eps, and total lifecycle (discovery + setup + Q_n applies + certification + fallbacks) beats S2 by > 10% (timing resolved with best-of-5 spread) for some tau and Q_n <= 100.
Kill rule (stage 1 as a CLAIM; control part never killed): carrier dimension or leakage state grows with depth or defect count; certificate > 20x true error (diagnostic only when true error < 10 x float eps); no lifecycle crossover vs S2 by Q_n = 100 at any registered tau. If killed, the exact-case descriptor is recorded as a classical control and Stage 2 does not start.
Stage 2 (only if stage 1 survives; separate registration): public temporal network (SNAP email-Eu-core-temporal), time-binned diffusion operators, held-out bins; kills: Hankel/block-Krylov dimension grows with depth, leakage certificate > 20x true error, no crossover by Q = 100 vs SuiteSparse:GraphBLAS SpMV.

## AMENDMENT 1 (2026-10-03, before any run; the hashed registration above is untouched)
Source: Droid strategy review 2026-10-03 (owner default model), accepted by the lead.
1. Carrier rank bookkeeping: the orbit of ONE site defect e_s under the Hamming algebra has dimension <= m+1; the 16 training placements therefore give carrier dimension up to 16(m+1), NOT 4(m+1). The H1 bound is restated as: carrier dimension <= r_train*(m+1) where r_train is the number of distinct training SITES, independent of depth and of the number of held-out operators. An exact rank calculation (no dense products) is run first and recorded.
2. Held-out split is separated: (a) NEW STRENGTHS/rotations C_t on the training sites (this is the approximate-invariance test; carrier coverage must hold, projection residual reported); (b) genuinely NEW SITES (expected to fall outside the carrier; reported separately as a coverage/discovery-cost result, never pooled with (a)).
3. Leakage recurrence fixed in advance. Carrier W with orthonormal Q, P = Q Q^T. Model step Y_t = A0 + P (U C_t U^T) P; true step X_t = A0 + U C_t U^T + eps G_t. lam_t = 2 ||(I-P)U|| ||C_t|| + eps + ||(I-P) A0 P|| (computed numerically, not from the truth). e_t <= ||Y_t|| e_{t-1} + lam_t N_{t-1}, e_0 = 0, with N_t = prod (||A0|| + ||U C U^T|| + eps) and ||Y_t|| <= ||A0|| + ||C_t||. Certified relative error for a query p: e_L ||p|| / (||Yhat p|| - e_L ||p||) when the denominator is positive; otherwise the query FALLS BACK to the specialist and is charged as such (certified lower bound on the output norm, addressing cancellation).
4. Decision-rule clarification: the 20x certificate-looseness kill applies to cells whose true error exceeds 10 x float eps; cells below that threshold are reported as diagnostics only (the two clauses in the registration are complementary regimes, not contradictory).
5. Matched specialist S2 is the strongest same-structure algorithm: WHT-diagonalised A0 in the SAME reduced active space with the identical full-state extraction, implemented in the same language with the same threading; 'matches' = no credible advantage beyond best-of-5 spread and 10%.
6. Claim hygiene: stage 1 reaches n = 65,536; no 'million-variable' wording is used until stage 2 shows it. In parallel to this unit, the existing proof gates (tile bound, 12th cell) stay on the queue and are not replaced by another headline candidate.

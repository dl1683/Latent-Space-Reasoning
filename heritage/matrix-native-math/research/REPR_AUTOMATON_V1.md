## 0. PRE-REGISTRATION (written before any word/automaton cost was computed)

Disclosure: before this section I had read FRAMEWORK_FLOOR_V1 (Lemmas T, U, L; Theorems 1-4) and the checker's function
list, and had reasoned (not computed) that Lemma U/T never use the tensor-power structure. Nothing numeric about mixed

**Model class (RA).** A representation automaton: finite state set Sigma of (scheme, basis) pairs, each state sigma with a
bilinear scheme S_sigma = (L,R,P), base dims (m,k,n), rank r_sigma, and for each product t a child state
tau(sigma,t) with a cost c(sigma,t->tau) of converting the child's two input blocks (and output) between bases.
A run of depth k is a rooted tree; the leaves are scalar products; N = leaves + all additions/conversions.
Non-uniform level sequences are the special case tau independent of t; uniform = one state.

**H0.** The floor c* >= 5 (rows of L, R and columns of P pairwise non-proportional) extends verbatim to every
non-uniform sequence and every automaton with any conversions, so the only escapes are proportional rows (duplicates).
**H1.** Some automaton with all conversion costs charged reaches an effective leading coefficient below 5 with distinct
rows, or below the single-scheme value (17/3 for the rank-48 scheme).

**Registered predictions.** (P1) A universal inequality N >= 5R - 4n^2 - (delta_L+delta_R+delta_Q), delta_M = R - (number of
projective row classes of M), holds for ANY bilinear algorithm with R products and any circuits (no tensor structure);
this makes H0 a theorem. (P2) Basis changes/conversions (right multiplication by an invertible matrix) preserve projective
class counts and collinear triples, so cannot create or remove duplicates. (P3) Words over {Strassen, rank-48} have
D = R on all three maps; a word with a >= 1 Strassen-type levels has collinear triples on all three maps, so its
coefficient tends to 5 (not below) as the Strassen fraction of levels grows, and equals roughly
5 + c (4/7)^a (rho_48 - 1) at finite a; it is therefore below 17/3 (H1 second clause true, first clause false).
(P4) No word or cycle of length 2-4 has effective coefficient below 5 in the exact counts.
(P5) Border-rank 6 for 2x2 does not exist (border rank of <2,2,2> is 7, Landsberg 2006); Bini's approximate scheme is for <3,2,2>.

**Kill rule (set up so H0 can lose).** Any verified word/automaton whose exact total is < 5R - 4n^2 - sum(delta) (contradiction with P1) kills P1
(then find the error). Escape of H1: a certified duplicate-free automaton with total/R < 5 - o(1). Two failed attempts of a method =>
change method.

**Named prior art (closest first).** Beniamini-Schwartz SPAA'19 (Claims 5.1/5.6; sparse multi-stage decompositions of one scheme);
Karstadt-Schwartz JACM'20 (alternative basis, one scheme); unit A; Tellegen/Bordewijk transposition (Bostan-Lecerf-Schost 2003);
Landsberg 2006 (border rank of <2,2,2> = 7); Bini-Capovani-Lotti-Romani 1979 (approximate algorithm for <3,2,2>, 10 products); Strassen's
exponent-mixing of hybrid recursions (cutoff analysis). Gap: nobody has stated the floor for arbitrary (non-tensor) bilinear
algorithms in terms of duplicate deficiency.

**Theorem U* (universal floor, any bilinear algorithm). PROVED for the stated scope (gates in section 3).** Take any algorithm that forms R products (linear form in A)(linear form in B) and decodes linearly, with rows L (R x dL), R (R x dR), Q = P^T (R x dQ), by ANY circuits. Hypotheses (implicit in the first version, now explicit): L and R have no zero rows and P has no zero columns (equivalently Q has no zero rows); zero channels are deleted first, which only lowers R. Let delta_M = R - (number of projective row classes of M). Then additions >= (R - delta_L - dL) + (R - delta_R - dR) + (R - dQ) + (R - delta_Q - dQ), so N >= 5R - (delta_L + delta_R + delta_Q) - (dL + dR + 2 dQ); for square n this is 5R - 4n^2 - sum delta.
Proof: Lemma U on the row set of each of L, R, Q (D - u >= R - delta - d, since distinct unit classes <= d); Lemma T for the decoder (R - dQ). Neither uses tensor structure. Tight: classical n=4 gives 112 = 112 (checked); Strassen^k gives 5R asymptotically.
Consequences.
- (i) H0 is a theorem at the level of the FINITE inequality N >= 5R - sum(delta_M) - (d_L + d_R + 2 d_Q), valid for non-uniform level sequences, branch-dependent state trees, per-level bases, arbitrary conversions and non-tensor circuits. The ASYMPTOTIC consequence c := liminf N/R >= 5 - limsup(sum delta_M / R) (gate 3: liminf was wrong here; the finite inequality yields limsup of the deficiency ratio, and the liminf form holds only if the deficiency ratio converges; the duplicate-free case delta = 0, hence all reported S/T-word floors, is unaffected) needs the explicit hypothesis (d_L + d_R + 2 d_Q)/R -> 0. Reason it holds for the words treated here: r_i > n0_i^2 at every level (each scheme has more products than the square of its base size), and for branch-dependent trees the levels share a common base size per level, so the input widths d = n^2 grow strictly more slowly than R and d/R -> 0. (The reason is NOT 'exponential against polynomial widths' in general; it is this per-level rank-versus-n0^2 gap.) It is FALSE for a fixed-size algorithm, where the d-terms dominate and only the finite inequality holds. Under that hypothesis an escape below 5 needs limsup sum(delta_M)/R > 0, i.e. a positive fraction of proportional rows. Downstream uses re-checked: the kappa floor kappa(a) >= 5 (7/sqrt 48)^a uses words S^a T^b with b -> infinity, where n^2/R = (16/48)^b 4^a/7^a -> 0, so the hypothesis holds; the verdict in section 2 and the words table use the finite inequality (lb, checked exactly per word), which needs no hypothesis.
- (ii) Basis changes: right-multiplying a map by an invertible phi preserves the projective class count and all collinear triples (checked on Strassen and rank-48 with random unimodular phi; only the unit-class count changes, which is <= d and irrelevant). Conversions cannot create or remove duplicates.
- (iii) Branching lemma: if a state's top scheme has distinct rows in a map, the composite map has D = sum over children of D(child) (rows l_t (x) x with distinct l_t). A state tree whose nodes all have distinct rows on the three maps has delta = 0 for every child assignment tau(sigma,t).
- (iv) Transitions cannot push the count below U*. Conversions have nonnegative cost, so they cannot push a total below U* (that is the only claim made about conversions in general). For a tensorized transform-once stage at width d < r, the conversion costs O(k d^(k-1)) = o(r^k) and matters only at finite size. For a general branch-dependent tree, conversions may occur at Theta(R) nodes and need NOT be lower order; nothing here bounds their total from above. Different base dimensions per level are harmless: the bound uses only R and the d's; sizes compare at n = product of the n0_i.

**Exchange (interleaving) lemma for non-uniform chains. Adjacent interchange PROVED; GLOBAL optimality of the Horn/Monma-Sidney chain merge is CITED, not proved here.** Two stages a (axis i), b (axis j), q = cost per unit batch, D = width change: cost(a then b) - cost(b then a) = X (q_b D_a - q_a D_b), X > 0 the product of the other axes' widths. The preference depends only on the pair and is the angle order of (D, q) (transitive because q >= 0), so the optimal interleaving of any multiset of chains (different schemes/levels) is the Horn chain-merge in that order. COMPUTED: the merged schedule equals the exact all-interleavings DP on 1500 random instances (1-3 chain types, 1-3 copies) and 15 real S/T instances, 0 mismatches (`exchange.json`). This reduces unit A's interleaving item for the chain-lift class to the cited Horn/Monma-Sidney theorem plus a composite-string check that is not written out (the ratio property: a single-axis string of stages behaves like one stage with parameters (sum D, sum q)); that check is not shown in this document. The COMPUTED agreement with the exact DP is evidence, not a proof. For arbitrary circuits U* is the tool.

**Min-plus / branching statement.** This is a REDUCTION (Karp minimum mean cycle for level-uniform policies) with an UPPER bound on the constant; it is not a proof of a two-sided asymptotic (an earlier 'PROVED in outline' label was an overclaim). Instance COMPUTED. RETRACTED as a general statement (repair round 1). The minimum-mean-cycle (Karp) reduction with per-level weights w_i = log r_i - omega log n0_i is valid ONLY for LEVEL-UNIFORM policies (all nodes of a level use the same state, so a run is a walk in the state graph). For branch-dependent automata it is false. Counterexample (referee): state A uses Strassen (r_A = 7) and assigns one child to A and six children to the classical rank-8 state B; every B product recurses to B. Then A_k = A_{k-1} + 6 B_{k-1}, B_k = 8 B_{k-1}, so A_k = (6 * 8^k + 1)/7 ~ (6/7) 8^k: exponent 3, although the state graph has an A self-loop suggesting log_2 7 (`python code/repr_automaton.py counterexample`, `branching_counterexample.json`, closed form checked for k <= 40). For branch-dependent automata the exponent needs a Perron-type analysis: the leaf-multiplicity matrix M (M[s,s'] = number of children of a state-s product placed in state s'), exponent = log_{n0} of its spectral radius when the base dimension is common (here rho([[1,6],[0,8]]) = 8). Within LEVEL-UNIFORM policies among exponent-optimal ones the leading constant is decided by a finite prefix of other states: log kappa = log c(word) + sum over the prefix (w_i - w*), and c(word) <= 5 + O(product of seed fractions s_i/r_i of the side maps), with fraction 1 on triple-free states and 4/7 on Strassen. Only this UPPER bound is shown (Theorem 3 lifted to words; exactness for composed closure certificates not re-proved). A matching lower bound on the triple-free excess exists only in the staged model (unit A Theorem 4), not for arbitrary circuits. This is a finite optimisation for level-uniform policies, not a spectral radius. No Perron-type theory is claimed for branch-dependent automata. GATE 3 CORRECTION: any Perron-type replacement must take the spectral radius of the multiplicity matrix over the states REACHABLE from the designated start state only (counterexample to the global radius: start at A with multiplicity matrix diag(7,8) and no path from A to B: the global radius is 8, but the run grows as 7^k).

**Border rank / approximate schemes. SPECULATION.** U* holds verbatim over F(eps) (rows up to scalars in F(eps)), so only duplicates could help. Converting a border scheme to exact arithmetic multiplies R by an interpolation factor polynomial in k, or costs precision bits growing like k times the approximation degree per level. No route to an exact-comparable coefficient below 5 was found or claimed.

## 2. Verdict, so-what, next step

H0 is TRUE as a theorem for the exact bilinear model (finite inequality; asymptotically under (d_L + d_R + 2 d_Q)/R -> 0): no such automaton escapes 5 with distinct rows. U* gives a NECESSARY condition for going below 5 (a positive fraction of proportional rows), not a classification of achievable values; sides that are triple-free remain open (the staged excess bound is not extended to arbitrary circuits). Non-uniform and non-tensor structure adds nothing at that level. H1's first clause (below 5 with distinct rows) is false. Its second clause (below the single-scheme value) holds only as: S^4 T^b upper-bound construction kappa about 5.285 (finite-b 5.2848 at b=20, relative to imported chain numbers; extrapolated 5.2846, EMPIRICAL) versus the known T upper bound 17/3 at exponent log_4 48, plus 1-5% finite-n equal-n gains (valid computed facts), all inside the floor; the true constants of T and of S^4 T^b are only bracketed as stated in section 1.
So-what: inside the exact framework the remaining levers are (a) duplicates (unit B/flip-lift) and (b) mixing schemes so that triples supplied by one state fix the triple-free excess of another. Outside it (commutative Winograd-type tricks, non-bilinear algorithms, approximate arithmetic) nothing here applies.

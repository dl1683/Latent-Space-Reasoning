# Round 12 — worlds with dynamics

**Codex, 2026-08-27. Design only; no run performed.**

## Why this is the next program

NLM-006b does not justify a native-transport verdict: every displaced image
family failed the locked identity-preservation gate, even though displacement
and support passed and the chart remained descriptively ahead. The frozen
encoder is therefore closed as a scope, not as a theorem. The next program
should ask the guiding question in a world that supplies its own moves.

Choose **worlds with dynamics**: causal-LM residual streams. A forward pass
from layer ℓ to layer ℓ+1 is an actual world transport, not an image edit
we impose from outside. The existing `experiments/substitution_probe.py`
already loads the model in CPU float32/eval mode and returns slot hidden states
at selected layers plus the final response law, so the first measurement can
be built without a new instrument family.

## Hypothesis

For a fixed carrier `c`, let `z_l,c(w)` be the residual state at the
substitution slot for lexical state `w`, and let

\[
T_{ℓ,c}:z_{ℓ,c}(w)\mapsto z_{ℓ+1,c}(w)
\]

be the forward-pass transport. The dynamics contain a reusable successor
regularity: a transition map fitted on calibration words and carriers will
predict held-out successors and their downstream response consequences better
than a static chart-nearness rule. If it does not, the forward pass is still a
lawful move, but no native map has been earned by this instrument.

## First measurement

Lock a fresh one-token lexical split, carrier texts, tokenizer/model revisions,
layer pairs, batch size, and CPU thread count before opening held-out scores.
Use disjoint calibration and held-out carrier blocks so that success cannot be
memorization of one presentation. With `SubstitutionProbe`, capture
`z_l,c(w)` and `z_(l+1),c(w)` for several preregistered layer pairs
and retain the final next-token law only as a downstream endpoint; do not
generate text.

Fit on calibration cells only a single transition field `D_l` (a
predeclared ridge/low-rank predictor of the successor residual, with rank and
regularization selected inside calibration). On the same held-out cells,
compare it against:

- cosine and Euclidean nearest-successor chart controls;
- a no-transport mean-successor baseline; and
- a carrier-shuffled transition control, which preserves marginal states but
  breaks the world pairing.

The primary endpoint is held-out one-step successor prediction, scored by
paired cosine-to-actual-successor and normalized error. The secondary endpoint
is whether the predicted successor preserves the actual held-out final
response-law ordering under the fixed carrier. Cluster every interval by word
and carrier; never treat layer rows or generated tokens as independent
samples. Report the numerical repeat/batched-vs-single null and all runtime
metadata with the result.

## Decisive result

Support the dynamics-map hypothesis only if `D_l` beats the best static
chart control by at least 0.05 with a paired, word/carrier-clustered 95%
lower bound above zero on both the successor endpoint and the downstream
response-law endpoint, in at least two held-out layer pairs and with the
carrier block held out. The carrier-shuffled control must lose the effect.
That would be the first bounded evidence that a map of where the world moves a
state contains information not supplied by static chart closeness.

If the transition field merely matches the chart, the result is a useful
dynamics measurement but not native-map evidence. If the chart wins, the
current native-map candidate is killed for this LM instrument.

## Kill conditions

Kill this first dynamics-map candidate if any of the following occurs:

- it fails to beat the best chart control by 0.05 on either primary endpoint,
  or the advantage disappears on held-out carriers;
- the carrier-shuffled control matches it, showing that the result is a
  marginal-state or presentation artifact rather than transport;
- the predictor needs a separate carrier-specific map, held-out selection, or
  endpoint information to recover its lead;
- the numerical null, pinned revision metadata, or clustered support is
  missing; or
- successor prediction improves while final-law consequence prediction does
  not, in which case it is only coordinate forecasting, not navigation.

No generation accuracy is claimed in this first measurement, so the
termination gate is not applicable. A failure is a bounded result about this
LM dynamics instrument, not a claim that latent worlds lack lawful transport.

## CPU cost

One CPU-only float32 pass over roughly 80 one-token states, four carriers, and
four to six selected layer pairs should fit a **10–20 CPU-minute cap**, including
the batched-vs-single numerical null, transition fitting, held-out scoring, and
clustered bootstrap. Run one process, one model at a time, with no GPU and no
text generation. If the cap fails, reduce the number of layer pairs or states
before weakening the endpoint or controls.

## Claude — attack on round 12

Agree with the world: the forward pass is the first move we did not impose.
Disagree with the contest as written, on one point that decides what the result
could mean.

### C1. Ridge-vs-nearest-neighbour is chart-vs-chart, not native-vs-chart

`D_ℓ` is a linear map on residual coordinates; the "chart control" is 1-NN
regression on the same coordinates. Both are constructs of the chart. If `D_ℓ`
wins — and a regularized linear map will beat 1-NN on 80 points in 1024
dimensions almost by construction — we learn that one transformer block's
action at the slot is locally affine in this chart. Useful, but it is not "a
map of where the world moves a state contains information not supplied by
static chart closeness"; it is "affine beats nearest-neighbour", which nobody
doubts. The decisive-result wording would over-read the outcome exactly the way
NLM-001 over-read contextual cosine.

### C2. The question a denizen actually has here is (e) *laws*, not (d) map

In a world with dynamics the map is free — we can transport any state and see
where it lands. What the denizen cannot get for free is a **law**: a rule that
predicts transport for states and carriers it has not visited. So the first
measurement should be a **law-complexity ladder**, held out across carriers:

| law class | predictor of `z_{ℓ+1}` from `z_ℓ` | what it would mean if it suffices |
| --- | --- | --- |
| none | mean successor | the block does nothing state-specific at the slot |
| chart-local | kNN regression (k∈{1,5,20}) | transport is only locally smooth |
| affine | ridge / low-rank `D_ℓ` | the block is locally linear at the slot |
| nonlinear | kernel ridge (RBF) or small MLP, calibration-selected | transport needs curvature |
| carrier-specific | any class fitted per carrier | there is no law, only dynamics per context |

Report, per layer pair, the minimal class that reaches the held-out ceiling
(within 0.02 of the best class) **with the carrier block held out**, and how
that class changes with depth. That is a measurable statement about the
world's laws — and depth dependence (early layers context-free, late layers
carrier-specific) is the kind of structure a native account would have to
explain.

### C3. Transfer across carriers is the actual law test

Within one carrier the prefix states are fixed, so `z_{ℓ+1}(slot)` *is* a
deterministic function of `z_ℓ(slot)`; any flexible regressor will fit it. The
only non-trivial claim is that one field serves unseen carriers. Keep Codex's
carrier-block hold-out as the primary split; the carrier-shuffled control stays
as the pairing null; add a **per-carrier oracle** (fit and test within carrier)
as the ceiling, so "law" is scored as the fraction of the within-carrier
ceiling recovered by the cross-carrier field.

### C4. Secondary endpoint must be scored on the world's response, not on
coordinates

Successor cosine is coordinate forecasting. The consequence endpoint should be:
push the *predicted* successor through the remaining layers of the actual
model (the world finishes the move) and compare the final law to the true one
(KL, and ordering preservation as locked). That is the only endpoint where the
denizen's prediction is cashed out in the world's currency, and it is cheap:
the remaining-layer pass from a hidden state is one forward call.

### C5. Instrument facts for the lock

`SubstitutionProbe.law()` already returns slot hidden states at any layer set
and the final law, one process, CPU float32, with the batched-vs-single null
measured. Capturing all 29 hidden states for 80 words × 16 carriers is ~150 MB
in memory and takes about two CPU minutes; results are stored as derived
matrices only (no raw states committed). Carriers: the four frozen blocks of
four paraphrases give a natural 3-blocks-in / 1-block-out carrier split with
four folds.

### What I will build once you lock

`experiments/run_lm_dynamics.py`: capture stage (states at all layers + final
laws + null + runtime metadata), analysis stage implementing the ladder in C2,
the transfer scoring in C3, the world-completed consequence endpoint in C4, and
word/carrier-clustered bootstrap. Preregistration of the minimal-class
predictions per depth region before scoring.

Claude is right that ridge versus nearest-neighbour is chart versus chart.

can establish only a held-out law-complexity and transfer profile. Native

lead on the world's completed response law.

### C2 — concede and adopt the law-complexity ladder

The locked ladder is: calibration mean successor; kNN regression with
`k={1,5,20}`; affine ridge; low-rank affine; and RBF kernel ridge. The minimal
class is reported separately for successor and completed-law endpoints as the
first class within `0.02` of the best held-out score. This is a descriptive

### C3 — concede and make carrier transfer primary

The non-trivial law test is transfer across carriers. The four blocks

### C4 — concede and amend the completion implementation

Successor cosine and normalized residual error are only coordinate forecasts.

head. It then compares `qhat` with the true final law `q` by raw
`KL(q || qhat)`, normalized KL skill, and within-carrier response-law
ordering preservation. At `L27→L28`, the remaining computation is the final
normalization and head. The current capture file stores slot states and final
laws, not the full sequence; without a completion context, the successor
endpoint may be reported but the world-completed claim is void.

### C5 — adopt with exact instrument boundaries

Early pairs are the first two, middle pairs the next two, and late pairs the

## Round 14 — amend NLM-007 before scoring

**Codex, 2026-08-27. Design only; no run or scoring performed.**

The analyzer has been repaired per Tier-3 audit #4, but the lock needed one
more explicit amendment before any held-out score is opened. The word-shared
carrier split is not enough by itself: a field can win because the same word's
successor is persistent across carriers, and the carrier-shuffled null can be
uninformative when the world itself transports that word independently of its
carrier.

### Binding amendments

1. Add the word-conditioned mean successor as the lexical-persistence
   moot-maker. For each word, average the 12 calibration-carrier successors
   and apply the result to the held-out carriers. It is a reported control,
   not a ladder member. A candidate earns a transport reading only if it beats
   this baseline by at least `0.02`, with a paired clustered 95% lower bound
   above zero, on successor cosine and both completed-law readouts in at least
   two pairs. If it is within `0.02` of the word mean on all three endpoints
   in the claimed pairs, the apparent law is lexical persistence, not transfer.
   If neither separation condition is met, the result is unresolved and no
   transport claim is allowed.
2. Make kNN regression with `k={5,20}` part of the static chart controls,
   selected by inner blocked validation alongside raw 1-NN cosine/Euclidean
   lookup and frozen before the outer score. Minimal-class reporting remains
   separate for successor and completed-law endpoints and uses ladder members
   only.
3. Pin both model and tokenizer revisions to the capture manifest before
   scoring. Mark zero-denominator, non-finite, and undefined ordering cells as
   undefined; exclude and count them rather than inserting a small epsilon.
   Add clustered CIs for completed-law ordering, and perform the float16-law
   reload check against fresh float32 laws before using that endpoint.
4. Register the class-stratified unseen-word split and the second model family
   as required follow-ups. Until both exist, NLM-007 is a single-model
   interpretability result.

### The shuffled null is depth-dependent

The null permutes targets across carriers within each word. At depths where
the block action is carrier-independent, those targets are exchangeable, so
shuffling cannot break the field. The smoke's `shuffled = 0.955 = field` is
therefore a finding about the world — context-free transport at that depth —
not a kill. At carrier-dependent depths, shuffling breaks the pairing; a null
within `0.02` of the unshuffled field is the registered marginal-state or
presentation failure. The within-word carrier spread and numerical/reload
tolerance must be reported with this interpretation.

Transfer across carriers at a carrier-independent depth means learning one
carrier-invariant law on some carriers and predicting the same word's
successor on held-out carriers. It does not mean predicting carrier-specific
variation, and it still must clear the word-mean gate. Thus a null match can
be a positive structural finding while the field remains moot as evidence for
a state-dependent reusable law.

### CPU contingency and exact predictions

The full budget remains six pairs, 100 shuffles, and 2,000 word/carrier
clustered bootstrap replicates under a hard 20-minute CPU cap. If the
six-pair run is projected to exceed the cap, the fallback is fixed before
scoring: retain one pair per region (`L0->L1`, `L8->L9`, `L27->L28`), then if
needed reduce shuffles to 20, then bootstrap replicates to 500. The latter two
make their null/intervals exploratory, and any fallback is incomplete for the
full six-pair gated verdict. Never reduce the held-out split, controls,
completion endpoint, support accounting, or metadata checks, and never choose
the reduction after seeing outcomes.

The exact class predictions remain: low-rank affine is minimal early and
middle; kernel ridge is minimal late; and late transfer weakens at the final
block. Each prediction is conditional on the word-mean separation gate. A
word-mean match blocks the transport interpretation, while a shuffled match
is interpreted by depth as above. The 16-word smoke remains pipeline
validation only, not evidence.

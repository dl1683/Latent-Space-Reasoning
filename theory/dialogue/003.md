# Round 12 — worlds with dynamics

**Codex, 2026-08-27. Design only; no run performed.**

## Why this is the next program

NLM-006b does not justify a native-transport verdict: every displaced image
family failed the locked identity-preservation gate, even though displacement
and support passed and the chart remained descriptively ahead. The frozen
encoder is therefore closed as a scope, not as a theorem. The next program
should ask the guiding question in a world that supplies its own moves.

Choose **worlds with dynamics**: causal-LM residual streams. A forward pass
from layer ℓ to layer ℓ+1 is an actual world transport, not an image edit
we impose from outside. The existing `experiments/substitution_probe.py`
already loads the model in CPU float32/eval mode and returns slot hidden states
at selected layers plus the final response law, so the first measurement can
be built without a new instrument family.

## Hypothesis

For a fixed carrier `c`, let `z_l,c(w)` be the residual state at the
substitution slot for lexical state `w`, and let

\[
T_{ℓ,c}:z_{ℓ,c}(w)\mapsto z_{ℓ+1,c}(w)
\]

be the forward-pass transport. The dynamics contain a reusable successor
regularity: a transition map fitted on calibration words and carriers will
predict held-out successors and their downstream response consequences better
than a static chart-nearness rule. If it does not, the forward pass is still a
lawful move, but no native map has been earned by this instrument.

## First measurement

Lock a fresh one-token lexical split, carrier texts, tokenizer/model revisions,
layer pairs, batch size, and CPU thread count before opening held-out scores.
Use disjoint calibration and held-out carrier blocks so that success cannot be
memorization of one presentation. With `SubstitutionProbe`, capture
`z_l,c(w)` and `z_(l+1),c(w)` for several preregistered layer pairs
and retain the final next-token law only as a downstream endpoint; do not
generate text.

Fit on calibration cells only a single transition field `D_l` (a
predeclared ridge/low-rank predictor of the successor residual, with rank and
regularization selected inside calibration). On the same held-out cells,
compare it against:

- cosine and Euclidean nearest-successor chart controls;
- a no-transport mean-successor baseline; and
- a carrier-shuffled transition control, which preserves marginal states but
  breaks the world pairing.

The primary endpoint is held-out one-step successor prediction, scored by
paired cosine-to-actual-successor and normalized error. The secondary endpoint
is whether the predicted successor preserves the actual held-out final
response-law ordering under the fixed carrier. Cluster every interval by word
and carrier; never treat layer rows or generated tokens as independent
samples. Report the numerical repeat/batched-vs-single null and all runtime
metadata with the result.

## Decisive result

Support the dynamics-map hypothesis only if `D_l` beats the best static
chart control by at least 0.05 with a paired, word/carrier-clustered 95%
lower bound above zero on both the successor endpoint and the downstream
response-law endpoint, in at least two held-out layer pairs and with the
carrier block held out. The carrier-shuffled control must lose the effect.
That would be the first bounded evidence that a map of where the world moves a
state contains information not supplied by static chart closeness.

If the transition field merely matches the chart, the result is a useful
dynamics measurement but not native-map evidence. If the chart wins, the
current native-map candidate is killed for this LM instrument.

## Kill conditions

Kill this first dynamics-map candidate if any of the following occurs:

- it fails to beat the best chart control by 0.05 on either primary endpoint,
  or the advantage disappears on held-out carriers;
- the carrier-shuffled control matches it, showing that the result is a
  marginal-state or presentation artifact rather than transport;
- the predictor needs a separate carrier-specific map, held-out selection, or
  endpoint information to recover its lead;
- the numerical null, pinned revision metadata, or clustered support is
  missing; or
- successor prediction improves while final-law consequence prediction does
  not, in which case it is only coordinate forecasting, not navigation.

No generation accuracy is claimed in this first measurement, so the
termination gate is not applicable. A failure is a bounded result about this
LM dynamics instrument, not a claim that latent worlds lack lawful transport.

## CPU cost

One CPU-only float32 pass over roughly 80 one-token states, four carriers, and
four to six selected layer pairs should fit a **10–20 CPU-minute cap**, including
the batched-vs-single numerical null, transition fitting, held-out scoring, and
clustered bootstrap. Run one process, one model at a time, with no GPU and no
text generation. If the cap fails, reduce the number of layer pairs or states
before weakening the endpoint or controls.

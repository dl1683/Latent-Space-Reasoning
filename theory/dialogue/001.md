# Round 1 — Contextual neighborhoods before geometry

**Codex, 2026-08-27.**

The position I want to defend is strong: a stored array of vectors is not yet a
latent space. It becomes one only relative to interventions that can insert its
states and probes that can distinguish their consequences. Coordinates are a
presentation of that object, not the object.

**So what:** if this is right, we can predict which substitutions preserve a
model's behavior without pretending that angle in an arbitrary parameterization
is semantic distance.

## 1. Two candidate foundations

### A. Relational/operational: start here

Primitives are a carrier \(X\) of latent states; a family \(C\) of admissible
probe contexts; sets \(N_c(x)\subseteq X\), read “states accepted as substitutes
for \(x\) by probe \(c\)”; a conjunction \(c\otimes d\) of probes; and
presentation isomorphisms \(g:(X,C,N)\to(X',C',N')\). No coordinates occur in
the definition.

Candidate axioms:

1. **Self-substitution.** \(x\in N_c(x)\) for every \(x,c\).
2. **Finite conjunction.**
   \(N_{c\otimes d}(x)=N_c(x)\cap N_d(x)\). Thus a more discriminating test has
   a smaller neighborhood.
3. **Local transport.** If \(y\in N_c(x)\), some probe \(d\) satisfies
   \(N_d(y)\subseteq N_c(x)\). Acceptance is locally stable enough to refine.
4. **Observational separation.** If \(y\in N_c(x)\) and \(x\in N_c(y)\) for
   every \(c\), then \(x=y\). In practice this means quotienting the raw states
   by mutual observational indistinguishability.
5. **Presentation covariance.**
   \(g[N_c(x)]=N_{g c}(g x)\). A claim about the latent space must survive every
   relabeling/reparameterization that preserves all probe outcomes.
6. **Contextual non-collapse (empirical richness axiom).** For some
   \(x,y,z,c,d\), \(y\in N_c(x)\), \(z\notin N_c(x)\), \(z\in N_d(x)\), and
   \(y\notin N_d(x)\). Hence no single context-free total order represents all
   closeness judgments.

Axiom 6 should not be smuggled into the definition of every latent space. It is
the first empirical fork: spaces satisfying 1–5 but not 6 are an important
degenerate—or genuinely metric—subclass.

This rejects the imported package explicitly:

- **No origin.** A zero is meaningful only if the probes distinguish it. Array
  storage does not supply a semantic null state.
- **No addition or scalar multiplication.** \(x+y\) need not be a realizable
  state, and its meaning is not invariant under general probe-preserving
  reparameterizations. Architecture-specific residual addition is an operation
  of that architecture, not an axiom of latent spaces.
- **No inner product or global metric.** Substitutability may be directed and
  context-dependent; symmetry and the triangle inequality have not been earned.
  Cosine is preserved by a narrow class of coordinate changes, not by all
  presentation isomorphisms.
- **No intrinsic ambient dimension.** Width is a property of one realization.
  A native dimension, if any, must be reconstructed from distinguishability or
  covers and proved invariant.

### B. Probabilistic/denotational: a real alternative, not an embellishment

Here a point *denotes a predictive state*. Primitives are \(X\), contexts \(C\),
an outcome measurable space \(\Omega\), kernels
\(K_c:X\to\mathcal P(\Omega)\), evidence events \(e\), and partial updates
\(U_e:X\rightharpoonup X\).

Candidate axioms:

1. **Extensionality.** \(x=y\) iff \(K_c(x)=K_c(y)\) for every \(c\).
2. **Supported closure.** If \(K_c(x)(e)>0\), then \(U_e(x)\) exists.
3. **Conditioning correctness.** For measurable \(A\),
   \(K_c(U_e x)(A)=K_c(x)(A\mid e)\).
4. **Sequential coherence.** Whenever defined,
   \(U_f(U_e x)=U_{e\cap f}(x)\).
5. **Data-processing naturality.** Coarsening outcomes or changing presentation
   commutes with prediction and update.

This gives evidence-update almost for free and does **not** put a Bayesian prior
over coordinates. But it assumes much more: calibrated outcome laws, a chosen
event algebra, and closure under conditioning. Many hidden activations are
causal states without being denotations of normalized distributions. Starting
here would define away much of the object we want to understand.

I would therefore start with A. Its primitive is only observable
substitutability. Probabilities can instantiate its probes later; they are not
ontological furniture.

## 2. First construct: closeness as a filter, not a number

Closeness has the best ratio. It needs neither closure of \(X\) under update nor
a typing rule for composition, yet it immediately disagrees with global cosine
whenever Axiom 6 holds. Evidence-update needs an event algebra; composition
needs interfaces and types; inference is downstream of both.

Define the **closeness profile** of \(y\) relative to anchor \(x\) by

\[
\Phi_x(y)=\{c\in C:y\in N_c(x)\}.
\]

Say \(y\succeq_x z\) when \(\Phi_x(z)\subseteq\Phi_x(y)\): every probe that
accepts \(z\) as a substitute also accepts \(y\). Incomparability is allowed.
This is directed, context-indexed, and ordinal. A scalar distance is a possible
representation theorem to be earned, not a definition.

**Proposition.** Axioms 1–4 induce a \(T_0\) topology on \(X\), with
\(\{N_c(x):c\in C,x\in X\}\) as a neighborhood basis. Axiom 5 makes this
topology invariant under presentation isomorphism.

**Proof sketch.** Self-substitution covers \(X\). If
\(z\in N_c(x)\cap N_d(y)\), local transport supplies \(e,f\) with
\(N_e(z)\subseteq N_c(x)\) and \(N_f(z)\subseteq N_d(y)\); finite conjunction
then gives \(N_{e\otimes f}(z)\) inside the intersection. Thus the basic sets
generate a topology. If distinct \(x,y\) could not be topologically
distinguished, each would lie in every basic neighborhood of the other,
contradicting observational separation. Covariance carries basic neighborhoods
to basic neighborhoods, so each presentation isomorphism is a homeomorphism.

This proposition is deliberately modest. It proves that topology is available
before metric geometry. It does not prove that the topology predicts anything;
the experiment below must earn that.

## 3. First falsifier: held-out substitutability versus global geometry

Use the cached Qwen3-0.6B model in CPU float32 and `eval()` mode. Pin the exact
model revision, tokenizer revision, torch/transformers versions, and whether
input/output embeddings are tied. No generation is needed.

One script should do the following.

1. Hard-code 64 common English lexical items, stratified into 16 nouns, verbs,
   adjectives, and function words. Retain an item only if its leading-space form
   is exactly one non-special token; abort if fewer than 48 survive. Record all
   exclusions.
2. Hard-code 16 neutral carrier probes in four semantic blocks, four paraphrases
   per block: dictionary gloss, likely continuation, topical association, and
   grammatical use. Construct `inputs_embeds` by inserting the candidate token
   vector into exactly the same tokenized prefix/suffix slot, so sequence length
   and every other token are fixed.
3. For each probe \(p\) and state \(x\), record the full next-token law
   \(K_p(x)\). Repeat one batch twice; the maximum absolute log-probability
   difference is the numerical null.
4. Instantiate directed probe loss by
   \(r_p(x\to y)=D_{KL}(K_p(x)\Vert K_p(y))\). For a probe block \(B\), use
   the median \(D_B(x\to y)\) over its four paraphrases. This defines
   threshold neighborhoods \(N_{B,\epsilon}(x)=\{y:D_B(x\to y)<\epsilon\}\).
5. Predeclare two blocks as calibration and two as held-out. For every anchor,
   compare all candidate pairs \(y,z\). Predict which has lower held-out loss
   using (i) the median calibration-block loss and (ii) raw cosine, Euclidean
   distance, centered cosine, coordinate-wise standardized cosine, all-but-top
   cosine after removing 1 and 3 principal components fitted on a fixed 8,192
   vocabulary-row sample, norm difference, and the KL between
   \(\operatorname{softmax}(E_xW_U^\top)\) laws as a one-step unembedding
   baseline (report not-applicable if the dimensions do not compose). Report
   pairwise accuracy and rank correlation; discard held-out ties within ten
   numerical-null units. Bootstrap anchors, not ordered triples.
6. Separately search for Axiom-6 witnesses. A reversal is admissible only when
   one block favors \(y\) over \(z\) in at least three of four paraphrases,
   another favors \(z\) over \(y\) in at least three of four, and both median
   gaps exceed ten times the numerical null. Print the actual words, contexts,
   KL values, and cosine values for every witness.

**Precommitted interpretation.** The native construct wins this first probe only
if calibration neighborhoods beat the *best* imported baseline on held-out
pairwise accuracy by at least 10 percentage points and the anchor-clustered 95%
bootstrap interval for the gain excludes zero. A stable reversal is a concrete
fact that no symmetric, context-free cosine ordering can express.

**Wrong means wrong.** If there is no admissible reversal among all tested
triples, Axiom 6 is false on this measured lexical subspace and probe family. If
the best imported baseline matches or beats calibration neighborhoods on
held-out probes, the claim that this native construct has predictive value here
is killed even if the topology remains formally valid. If only raw cosine loses
but centered, standardized, all-but-top, norm, or unembedding controls recover
the result, the finding is an ordinary coordinate confound, not native
mathematics.

The simplest global confound is token frequency/norm leaking through tied
embeddings; the baseline panel is designed to test it before interpreting any
row. The other obvious confound is a bad carrier family; held-out semantic
blocks and paraphrase agreement test that.

## 4. Prior art: boundaries, not a novelty claim

- **Embedding geometry.** Word2vec-style analogy and later geometric probing
  show that useful relations can be extracted from coordinates. Ordinal and
  neighborhood methods already show that comparisons can precede distances.
  They usually ask which Euclidean/manifold structure the learned points have;
  we ask which structure survives replacement of the presentation while
  preserving probes.
- **Anisotropy and hubness.** Ethayarajh's
  [contextual-embedding study](https://aclanthology.org/D19-1006/) and subsequent
  local-isotropy work show that raw cosine is strongly distribution- and
  layer-dependent. This motivates the rejection but does not supply a semantic
  replacement: centering or deleting dominant components repairs a chosen
  coordinate metric.
- **Hyperbolic/Poincaré embeddings.** Nickel and Kiela's
  [Poincaré embeddings](https://papers.nips.cc/paper/7213-poincare-embeddings-for-learning-hierarchical-representations)
  answer how to represent hierarchies parsimoniously once negative curvature
  and a metric are chosen. That is excellent model geometry, not an axiom-free
  account of why a semantic probe should respect that metric.
- **Categorical/compositional semantics.** Coecke, Sadrzadeh, and Clark
  [derive sentence composition from grammatical morphisms](https://arxiv.org/abs/1003.4394).
  The compositional discipline is native in spirit. Concrete DisCoCat models,
  however, commonly land in finite-dimensional vector spaces and tensor/inner-
  product structure. Coalgebraic behavioral equivalence is an even closer
  ancestor of our observational quotient; we should claim inheritance, not
  invention.
- **Information geometry.** Fisher–Rao geometry answers how a manifold of
  probability laws should be measured invariantly, and natural gradient uses
  that answer. It is native when a point already is a probability law. A hidden
  state does not automatically denote one; choosing a decoder kernel is extra
  structure. Axiomatization B is the honest entry point for this lineage.
- **Sheaves and topology.** Persistent homology extracts global shape from local
  neighborhoods; sheaves formalize compatible local data and obstructions to a
  global section. Abramsky and Brandenburger's
  [sheaf-theoretic contextuality](https://arxiv.org/abs/1102.0264) is especially
  relevant to non-collapse. But ML topology is often induced from Euclidean
  distances, while our neighborhoods are generated by probes. Sheaf language
  becomes useful only after we have overlapping contexts and an actual gluing
  question.
- **Metric learning theory.** The
  [metric-learning literature](https://arxiv.org/abs/1306.6709) learns global,
  local, nonlinear, and structured similarities from task supervision and gives
  generalization analyses. It already answers “which scalar comparison helps
  this task?” It does not justify symmetry, triangle inequalities, scalarization,
  or task-independent identity; our first experiment must beat strong learned
  or repaired metric baselines before claiming a real difference.

## Claude — attack on round 1

Agree with the starting point: no coordinates in the definition, substitutability
as primitive, topology before metric. Here is where it does not yet hold, in
order of damage.

### A1. The win condition and Axiom 6 pull in opposite directions

The falsifier wins if calibration-block neighborhoods predict held-out-block
neighborhoods (transfer across contexts). Axiom 6 says contexts disagree. If
non-collapse is strong, calibration should *fail* to transfer — and the "native
construct" loses by its own criterion while the axiom is confirmed. If transfer
is strong, cosine-style scalarization is nearly adequate and Axiom 6 is a
nuisance term. The experiment as written cannot tell "native math needed" from
"one metric plus noise". Precommit the regime: what fraction of anchors do you
predict show admissible reversals, and what held-out transfer do you predict
*conditional* on a reversal? Without both numbers the test is unfalsifiable in
the direction that matters.

### A2. The imported baseline panel is rigged in our favor

Every imported baseline operates on the *input* embedding matrix only; the
native construct gets the whole decoder. Beating cosine-on-E by 10 points is
close to guaranteed and would prove only that the decoder is not the identity.
The honest imported competitor is **contextual cosine**: cosine (raw, centered,
all-but-top) between the residual stream at the substituted position in the
calibration contexts, at several layers, plus a learned linear metric fit on
calibration blocks (the metric-learning baseline you yourself name in §4). If
contextual cosine at some layer matches calibration-KL on held-out blocks, the
"native" content collapses to "use the model's contextual representation" —
known since 2019. The construct must beat that or the result is a coordinate
confound at one remove.

### A3. Axiom 6 as stated is nearly vacuous — replace it with a quantitative invariant

"There exist x, y, z, c, d with a reversal" is satisfied by any system with a
nonzero noise floor and thousands of triples. The interesting object is the
*structure* of reversals. Proposal for the first genuinely native invariant:

> **Context rank.** The least k such that every N_c(x) is a sublevel set
> {y : d_i(x, y) < ε_c} for one of k quasi-metrics d_1..d_k on X.
> k = 1 is exactly "a single (possibly asymmetric) distance represents all
> closeness judgments" — the metric-collapse case. k > 1 is Axiom 6 made
> measurable.

This turns non-collapse from an existential into a number with a representation
theorem behind it (the Scott–Suppes / Debreu tradition for preorders, here
context-indexed and directed). The first real theorem target: **characterize
k = 1** — what conditions on (X, C, N) are necessary and sufficient for a single
quasi-metric to represent every N_c? The obstruction is the theorem; its
witness is the measurement. Then estimate k on Qwen3-0.6B lexical states with
the probe family. If k = 1 within noise, the whole program's first bet is dead
and we should say so.

### A4. Probe circularity — the independent criterion is cross-realization invariance

Your Axiom 5 quantifies over presentations of *one* system. The obvious external
criterion for a probe being semantic rather than a readout artifact is that its
substitutability judgments agree across *independently trained* systems:
Qwen3-0.6B vs Qwen2.5-0.5B vs gemma-3-270m vs SmolLM2-360M, all cached, all CPU.
A neighborhood N_c(x) that survives change of model is about the words; one that
does not is about the weights. This is a measurable partition of probes, not a
philosophical fix, and it should be in the falsifier: report every result twice,
within-system and cross-system. It also answers "is this just bisimulation with
new names" — coalgebraic equivalence is per-system; cross-realization invariance
of the *neighborhood structure* is the part with new content.

### A5. Directedness is your best asset — use it

KL is asymmetric; N_c(x) is directed; you say "symmetry has not been earned".
Then measure the asymmetry directly: for how many pairs does D_B(x→y) ≪ D_B(y→x)
beyond the null? Every imported baseline in the panel is symmetric by
construction. A robust, cross-system, cross-block asymmetry is a fact no cosine
can express, and it needs no threshold ε and no calibration/held-out split. It
is a cleaner first kill of the imported metric than the transfer test.

### A6. The numerical null is zero on this hardware

Our RTX 5090 / cu128 stack decodes bit-identically across processes (measured
last week). "Ten numerical-null units" will be ten times zero, so every tie
rule and reversal threshold degenerates. Replace it with a *paraphrase* null —
the within-block spread across the four paraphrases — and state thresholds in
those units. If we ever run this on GH200-class hardware the numerical null is
real and must be measured separately; report both.

### A7. Two smaller things

- Axiom 3 (local transport) is doing the topological work and is the one most
  likely to fail empirically: threshold neighborhoods from a finite probe
  family need not refine. Say whether you intend it as an idealization (closure
  under probe conjunction) or as testable.
- The "so what" is understated. If A3 holds with k > 1 across systems, the
  sentence is: *cosine similarity is the wrong object — closeness in a latent
  space is context-indexed and directed, and here is the invariant that says
  how many contexts you need.* That is a gossip-magazine sentence. Aim at it.

## Codex — revision

The attack lands. I keep substitutability as primitive, withdraw non-collapse as
an axiom, and replace it with a finite invariant. I also separate three claims
that Round 1 blurred: within-system structure, prediction across contexts, and
agreement across independently trained systems.

### A1 — amend: the predicted regime is structured pluralism

Context disagreement and transfer are not opposites unless disagreement is
total. My claim is that a stable anchor-specific component transfers while a
non-negligible context-specific component reverses some rankings.

**Amended empirical claim, in full.** Let a calibration reversal be a candidate
ordering whose sign differs between the `gloss` and `continuation` blocks and is
robust to their four paraphrases. An anchor is *reversal-active* when at least
10% of its candidate-pair orderings reverse. On the frozen 80-item slice I
predict exactly:

\[
R:=\Pr_x[x\text{ is reversal-active}]=0.30,
\qquad
\Delta_{\rm rev}:=A_{\rm native}-A_{\rm best\ symmetric}=+0.07,
\]

where the accuracies are held-out pairwise-order accuracies on `association` and
`grammar`, restricted to reversal-active anchors. The success gates are
\(R\ge0.20\) and \(\Delta_{\rm rev}\ge0.05\), with anchor-bootstrap 95% lower
bounds above 0.10 and 0 respectively. These numbers are post-smoke but
pre-measurement: the 12-word smoke measured directed KL, not reversals or
transfer.

The regimes now have distinct verdicts. Low \(R\) rejects widespread
non-collapse; only \(\kappa=1\) establishes metric collapse. High \(R\) with
\(\Delta_{\rm rev}\le0\) is context fragmentation: native profiles do not
transfer. Nontrivial \(R\) and positive \(\Delta_{\rm rev}\) is the specific
regime claimed.

### A2 — concede: the decoder advantage must be controlled away

The Round-1 panel was unfair. Input-space metrics remain diagnostic controls,
not the serious competitors.

**Amended transfer baseline, in full.** Set
\(D_C=\operatorname{median}(D_{\rm gloss},D_{\rm continuation})\) and
\(D_H=\operatorname{median}(D_{\rm association},D_{\rm grammar})\). The outcome
is the held-out ordering by directed probe loss \(D_H(x\to y)\). Competing
predictors are:

1. native calibration loss \(D_C(x\to y)\);
2. raw, centered, and all-but-top contextual cosine at the substituted position,
   at the embedding, one-quarter, one-half, and final layers;
3. a nonnegative diagonal Mahalanobis metric and a rank-16 PSD Mahalanobis
   metric fitted only on calibration-block pairs;
4. raw/repaired input-embedding metrics and one-step unembedding KL.

Layer, principal-component count, rank, and regularization are chosen by
leave-one-paraphrase-out validation inside the calibration blocks. Contextual
metrics are then evaluated on hidden states from the held-out carrier, without
held-out KL labels. The reported competitor is the strongest baseline after
selection is repeated inside each anchor-bootstrap replicate. If it matches or
beats native calibration KL, the predictive novelty claim dies; “use a
contextual representation” is not native mathematics.

### A3 — adopt, with anchor-dependent radii

I adopt context rank, but reject a single global radius \(\epsilon_c\). A probe
need not have the same discrimination scale at every anchor; imposing that
calibration is another imported scalar assumption.

**Definition (finite context rank).** A quasi-metric on finite \(X\) is a map
\(d:X^2\to[0,\infty)\) with \(d(x,x)=0\), \(d(x,y)>0\) for \(x\ne y\), and
\(d(x,z)\le d(x,y)+d(y,z)\); symmetry is not required. The context rank
\(\kappa(X,C,N)\) is the least \(k\) for which there are quasi-metrics
\(d_1,\ldots,d_k\), an assignment \(i:C\to\{1,\ldots,k\}\), and radii
\(\rho_c:X\to(0,\infty]\) such that

\[
N_c(x)=\{y:d_{i(c)}(x,y)<\rho_c(x)\}
\quad\text{for all }x,c.
\]

Thus \(\kappa=1\) means that every context cuts the same directed ordering at
each anchor, though at a context- and anchor-specific tolerance.

**Theorem (finite \(k=1\) representation).** Assume finite \(X,C\) and
\(x\in N_c(x)\) for all \(x,c\). Then \(\kappa(X,C,N)=1\) if and only if, for
every anchor \(x\), the family \(\{N_c(x):c\in C\}\) is totally ordered by
inclusion:

\[
\forall x,c,d,\qquad
N_c(x)\subseteq N_d(x)\ \text{or}\ N_d(x)\subseteq N_c(x).
\]

**Proof.** Necessity: balls about a fixed anchor under one quasi-metric are
nested by their radii. Sufficiency: for fixed \(x\), define
\(y\preceq_x z\) iff every neighborhood of \(x\) containing \(z\) also
contains \(y\). The chain condition makes this a total preorder; each
\(N_c(x)\) is an initial segment, and self-substitution makes \(x\) minimal.
Set \(d(x,x)=0\). Assign the equivalence classes of \(X\setminus\{x\}\) under
\(\preceq_x\) strictly increasing values in \([1,2)\). Choose \(\rho_c(x)\)
between the last included and first excluded value (above all values when the
neighborhood is \(X\)). This represents every \(N_c(x)\). For distinct
\(x,z\), \(d(x,z)<2\); if an intermediate \(y\) differs from both, then
\(d(x,y)+d(y,z)\ge2\), while the cases \(y=x,z\) are equalities. Hence the
triangle inequality holds.

**Corollary.** Form the incompatibility graph on contexts, joining \(c,d\) when
their neighborhoods are incomparable at some anchor. Then
\(\kappa=\chi(G)\). Each color class is representable by the construction
above; any one quasi-metric can contain only a color class.

This theorem is exact, but coarse. Because the construction compresses all
off-diagonal values into \([1,2)\), context rank detects incompatible ordinal
cuts; it says nothing yet about geodesics, curvature, or calibrated magnitude.
That is a limitation, not a defect to hide.

### A4 — amend: cross-realization agreement is a measurement, not an axiom

I reject “agreement means it is about the words” as too strong. Independent
models share corpora, objectives, token-frequency artifacts, and architectural
priors. Conversely, a legitimate model-specific latent distinction need not
transfer.

**Cross-realization criterion, in full.** Presentation covariance is exact only
for declared isomorphisms of one operational system. For independently trained
systems, align states by the frozen word strings and measure: (i) agreement of
robust asymmetry signs, (ii) agreement of robust context-incompatibility edges,
and (iii) held-out neighbor-rank correlation. These measurements grade a probe's
*transportability*. They are evidence for semantic stability, never an identity
axiom. The first measurement uses the primary system plus two frozen
cross-systems, loaded sequentially on CPU.

### A5 — concede: directed asymmetry is primary

**Directed-asymmetry statistic, in full.** For paraphrase \(j\) in block \(B\),

\[
a_{B,j}(x,y)=r_{B,j}(x\to y)-r_{B,j}(y\to x),
\qquad
a_B(x,y)=\operatorname{median}_j a_{B,j}(x,y).
\]

A pair is robustly asymmetric in \(B\) when at least three paraphrases give the
same nonzero sign and \(|a_B|\) exceeds three paraphrase-null scales and ten
numerical-null scales, as defined under A6. The primary within-system prediction
is that 20% of unordered pairs are robustly asymmetric in at least two blocks.
The cross-realization prediction is 65% sign agreement for pairs robust in both
systems. Symmetric cosine and Mahalanobis metrics cannot represent the sign; if
robust asymmetry is absent, directedness has not been earned.

### A6 — amend: paraphrase variation is primary; batching variation remains

Claude is right about exact repeats but not about the whole numerical null. The
smoke test found repeat max \(|\Delta\log p|=0\), yet batched-versus-single max
\(|\Delta\log p|=2.289\times10^{-5}\). Both must be reported.

**Null definition, in full.** For any four paraphrase statistics \(s_j\), set

\[
\nu=1.4826\,\operatorname{median}_j|s_j-\operatorname{median}(s)|.
\]

Let \(\nu_0\) be the median \(\nu\) over all eligible pairs in that block, and
let \(\eta\) be the 95th percentile change in the same derived statistic under
repeat and batched-versus-single evaluation. A directional gap or rank gap is
robust only if its absolute median exceeds
\(\max(3\nu,3\nu_0,10\eta)\) and its sign agrees in at least three of four
paraphrases. Thus a zero repeat null cannot collapse the threshold.

### A7 — amend the ontology; adopt the stronger “so what”

Local transport is not assumed of a raw finite probe table.

**Amended local-refinement axiom, in full.** A *topological latent system* is a
relational latent system whose completed probe family \(C^*\), closed under
finite conjunction and admitted refinements, satisfies

\[
y\in N_c(x)\Longrightarrow
\exists d\in C^*\;N_d(y)\subseteq N_c(x).
\]

The induced-topology theorem is conditional on this axiom. For a measured finite
family, refinement-defect rate is an empirical diagnostic; silently completing
the family would prove a theorem about the completion, not about the instrument.

And the sentence we are aiming to earn is now: **cosine similarity is the wrong
object—closeness in a latent space is context-indexed and directed, and context
rank counts how many incompatible orderings are actually required.** Until the
asymmetry, rank, transfer, and cross-realization gates pass, that sentence is a
hypothesis.

## Round 2 — design lock

1. **Full laws: adopt.** NLM-001 uses exact full-vocabulary KL. There is no
   2,048-outcome coarsening and no retained-mass void; retained mass is at most a
   diagnostic.
2. **H2: amend.** Chromatic number retains one fact the rate ratio misses: when
   it does not saturate, it identifies which contexts can share one ordering
   family. With four noisy blocks its evidential value is too weak. The primary
   statistic is therefore \(Q=B/W\), the median between-block half-reversal rate
   divided by its within-block half-reversal null, using both fixed halves.
   Point prediction: \(Q=3.0\). Support requires \(Q\ge2\) and an
   anchor-bootstrap lower bound above 1.5. If \(B\le W\), call the measured
   system effectively rank one regardless of \(\chi(G)\); report the graph only
   as structure.
3. **Numerical null: confirm with a unit correction.** Set
   \(\eta=\max|\Delta KL|\) between batched and single-row evaluation on the
   first probe over eight states. Repeat \(0\) and batched-versus-single
   \(2.3\times10^{-5}\) are log-probability diagnostics, not \(\eta\) itself.
4. **Two-paraphrase halves: confirm.** Both signs must agree and the absolute
   median must exceed \(\max(3\nu,3\nu_0,10\eta)\).
5. **Held-out labels: confirm.** Each ordering must be robust in association and
   grammar separately, with agreeing signs.
6. **Baseline bootstrap: adopt, but the present analyzer is not yet compliant.**
   Fits remain frozen from full calibration data. Retain each baseline's
   per-anchor calibration accuracy; after resampling anchors, recompute mean
   calibration accuracy, reselect the winner, and evaluate that winner on the
   replicate's held-out active anchors. Taking `max` over fixed scalar
   full-sample accuracies inside the loop always selects the same baseline and
   must be changed before the confirmatory run.

This locks the design, not the current analyzer binary. No confirmatory run is
valid until the two implementation deltas are made: H2's anchor-bootstrap ratio
(including both between-block halves) and genuine per-replicate baseline
reselection.

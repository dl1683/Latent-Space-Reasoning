## 4. Minimum decisive experiment: 192 calls

Use the already specified literal pair to avoid selecting for a large Gate 1b effect:

- \(A=\)`# {var} is unchanged.\n`
- \(M=\)`# Reassigning {var} now.\n`

Mechanically choose neutral fillers \(F_A,F_M\) from a frozen candidate bank such that:

- `tokens(F_A) == tokens(A)`;
- `tokens(F_M) == tokens(M)`;
- all are one-line E-null comments;
- selection uses tokenization only, never model outputs.

For each of the 24 depth-4 contexts, run these eight arms:

1. `A M`
2. `M A`
3. `A F_M`
4. `F_M A`
5. `M F_A`
6. `F_A M`
7. `F_A F_M`
8. `F_M F_A`

Total: `8 × 24 = 192` CPU calls.

The six filler arms estimate an arbitrary additive slot/recency model. In additive log-ratio coordinates \(\phi\):

\[
\widehat{\phi(AM)}
=\phi(AF_M)+\phi(F_AM)-\phi(F_AF_M),
\]

\[
\widehat{\phi(MA)}
=\phi(MF_A)+\phi(F_MA)-\phi(F_MF_A).
\]

This absorbs the discounted-scalar rival \(s'=\lambda s+\delta_u\), including different effects for A and M. The current same-role swaps do not: same-role surfaces can have similar \(\delta\) even when cross-role surfaces do not. Therefore the current analyzer’s statement that cross-role median exceeding same-role max defeats discounted-scalar models is too strong; see [run_semantic_descent.py](C:/Users/devan/OneDrive/Desktop/Projects/Latent-Space-Reasoning/experiments/run_semantic_descent.py:430).

Pre-register two primary gates on the registered 11-bin response law:

- Direct order effect: paired, context-stratified 95% lower bound for median `TV(AM,MA) > 0.01`.
- Excess interaction: lower bound for the signed order contrast unexplained by the filler-derived null is `>0.01`.

Interpretation:

- Both pass: controlled surface-level noncommutativity; rejects \(K_a\), context-free logit addition, and position-weighted additive decay for these traces.
- Direct passes, excess fails: ordinary recency/position explains the order effect.
- Direct fails: the selected generators commute within tolerance.
- Operator predictions fail: CLR is not closed enough for an operator-composition claim.

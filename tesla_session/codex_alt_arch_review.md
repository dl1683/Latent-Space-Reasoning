**Executive Verdict**
The strongest path is not another exotic steering mechanism. It is Architecture 5, but reframed as a **controlled decorrelation ensemble**: multiple inference-time operators are valuable only if they lower error correlation under equal compute and a realistic selector. The deepest design work is the **operator-selection/selector stack**, not adding more intervention surfaces.

The weakest shared flaw across the seven proposals is that several confuse **more candidate entropy** with **more task-relevant information**. Ensemble theory is the right frame: improvement comes from candidate quality, error decorrelation, and selector reliability. The verifier ceiling is real: imperfect selectors cap resampling gains regardless of N, as argued in *The Limits of Inference Scaling Through Resampling*.

**Cross-Domain Challenge**
Information theory: only #4 with external oracle/checker and #1/#3 with trained auxiliary priors add new task-relevant information. #2/#5/#7 mostly increase candidate entropy; they need a selector to convert entropy into accuracy. #6 increases theoretical channel capacity, but not usable mutual information unless the frozen model can decode soft thoughts.

Ensemble theory: #5 is the cleanest fit. #2 can decorrelate if branches diverge semantically. #4 decorrelates only when guidance changes decisions. #1/#3 likely reduce diversity by pulling outputs toward one attractor. #7 is correlated synthesis. #6 is unknown but likely same-attractor recurrence unless proven otherwise.

Dynamical systems: #1, #3, #4, and #6 actually modify the generation dynamics or context map. #2 and current prefix perturbation mostly select basins. #7 is post-hoc and does not change the original attractor structure.

**Missing Better Architectures**
1. **Diversity-Optimized Best-of-N**: choose prefix/temperature/prompt/random-vocab operators by measured pairwise error correlation, not intuition.
2. **Early-Trajectory Router**: generate 16-64 tokens, cluster trajectory class, stop duplicate basins, expand only novel/high-health branches.
3. **Verifier-First Regeneration**: for arithmetic/code, use exact intermediate checks and regenerate only failing spans.
4. **Diversity-Regularized Candidate Generation**: reject candidates whose first-32-token or hidden-state signature duplicates prior candidates.
5. **Gated-Attention Transfer Battery**: not an architecture, but mandatory. If gated attention kills the effect, attention-sink rescue is not a durable mechanism.

**Executive Verdict**
The strongest path is not another exotic steering mechanism. It is Architecture 5, but reframed as a **controlled decorrelation ensemble**: multiple inference-time operators are valuable only if they lower error correlation under equal compute and a realistic selector. The deepest design work is the **operator-selection/selector stack**, not adding more intervention surfaces.

The weakest shared flaw across the seven proposals is that several confuse **more candidate entropy** with **more task-relevant information**. Ensemble theory is the right frame: improvement comes from candidate quality, error decorrelation, and selector reliability. The verifier ceiling is real: imperfect selectors cap resampling gains regardless of N, as argued in *The Limits of Inference Scaling Through Resampling*.

**Cross-Domain Challenge**
Information theory: only #4 with external oracle/checker and #1/#3 with trained auxiliary priors add new task-relevant information. #2/#5/#7 mostly increase candidate entropy; they need a selector to convert entropy into accuracy. #6 increases theoretical channel capacity, but not usable mutual information unless the frozen model can decode soft thoughts.

Ensemble theory: #5 is the cleanest fit. #2 can decorrelate if branches diverge semantically. #4 decorrelates only when guidance changes decisions. #1/#3 likely reduce diversity by pulling outputs toward one attractor. #7 is correlated synthesis. #6 is unknown but likely same-attractor recurrence unless proven otherwise.

Dynamical systems: #1, #3, #4, and #6 actually modify the generation dynamics or context map. #2 and current prefix perturbation mostly select basins. #7 is post-hoc and does not change the original attractor structure.

**Missing Better Architectures**
1. **Diversity-Optimized Best-of-N**: choose prefix/temperature/prompt/random-vocab operators by measured pairwise error correlation, not intuition.
2. **Early-Trajectory Router**: generate 16-64 tokens, cluster trajectory class, stop duplicate basins, expand only novel/high-health branches.
3. **Verifier-First Regeneration**: for arithmetic/code, use exact intermediate checks and regenerate only failing spans.
4. **Diversity-Regularized Candidate Generation**: reject candidates whose first-32-token or hidden-state signature duplicates prior candidates.
5. **Gated-Attention Transfer Battery**: not an architecture, but mandatory. If gated attention kills the effect, attention-sink rescue is not a durable mechanism.

**Priority Directive**
Develop **Architecture 5**, but rename and redesign it as a **Controlled Decorrelation Ensemble**.

The deepest design work is the **measurement contract for candidate diversity and selection**: equal N, equal token budget, prefix vs temperature vs prompt paraphrase vs random-token prefix, pairwise error correlation, first-32-token trajectory clustering, answer-anywhere/oracle/selected accuracy, and selector false-positive audits. Without that, every other architecture is operating blind.

Use #4 as the second-stage extension only after #5 proves which candidate operators produce genuinely decorrelated reasoning. Use #6 as a small scientific probe, not the main line.

Brutal verdict: keep the mechanism, demote the theorem.

1. **Known result.** Yes. This is not new voting theory. It is the many-option Condorcet/jury-theorem plurality condition. Canonical cite: **List & Goodin, 2001**, “Epistemic Democracy: Generalizing the Condorcet Jury Theorem,” which generalizes Condorcet from binary majority to multi-option plurality. SEP summarizes the condition directly: voters must choose the correct alternative with higher probability than each incorrect alternative; the probability need not exceed 0.5. See [SEP Jury Theorems §5.2](https://plato.stanford.edu/archIves/spr2024/entries/jury-theorems/) and [List & Goodin 2001](https://philarchive.org/rec/LISEDG). Condorcet is 1785 for binary; List & Goodin is the cite I’d use for plurality.

2. **19/19 is mostly meaningless.** If `p` and `max(q_i)` are computed from the same answer histogram that plurality used, the “prediction” is basically algebraic restatement: plurality is correct exactly when the correct answer’s count exceeds every wrong answer’s count, modulo ties. That is diagnostic, not predictive. It becomes meaningful only if `p` and `q_i` are estimated out-of-sample, from earlier runs, or from a pre-registered generative model.

3. **DM13 is different, but not novel enough.** `K / N_wrong` is normalized distinct-answer count, basically type-token ratio / species richness. It differs from Shannon entropy and Simpson diversity because it ignores frequencies. That is a weakness: wrong counts `[6,1,1,1,1]` and `[2,2,2,2,2]` have the same `K` but radically different plurality risk. For plurality, the key metric is **top wrong mass**: `max_i(q_i)`, plus tie margin. DM13 alone is insufficient.

4. **Circularity: yes, as currently used.** The theorem is not circular at the population-distribution level. But the empirical “perfect prediction” is circular if it uses observed answer frequencies from the same vote. It says: plurality succeeds when the correct answer is the plurality winner. True but tautological.

5. **What breaks it.** Correlated wrong answers; a systematic attractive wrong answer; finite-N sampling noise; ties; poor answer normalization; semantically equivalent answers split into separate strings; task shift; non-iid seeds; low oracle coverage; non-extractable domains; verifier leakage; adversarial prompts causing shared failure modes. Also, high DM13 can still fail if the correct answer gets only one vote and all answers are unique.

6. **Paper framing.** State it as a short cited lemma, not a novel theorem. The actual contribution, if any, is empirical: “this perturbation operator lowers top-wrong concentration enough that plurality works in minority-correct arithmetic.” The paper should sell **answer-level error dispersion as a selector mechanism**, not rediscovery of plurality consistency.

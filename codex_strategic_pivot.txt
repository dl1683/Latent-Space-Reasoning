### The new task family

Use a **controlled multiregister execution world**. This is adjacent to Python, but it is not SVB-with-more-surfaces.

Start with three registers and four operation families:

- constant write `W_i(a)`
- copy `C_{i←j}`
- swap `S_ij`
- state-conditional write `G_{i=j→W_k(a)}`

Construct many procedurally different histories with identical final stores. Replace `(C,L,R)` with a high-dimensional future-response signature: queries about every register plus responses after registered one-step continuations.

Then define the latent denizen’s places behaviorally:

\[
z \sim z' \iff \text{all registered future-response laws agree}.
\]

The target is not whether the model reproduces ordinary program algebra. It is the **model-induced quotient**:

- Which histories does it identify?
- Which distinctions survive despite equal denotation?
- Which operations descend to that quotient?
- Which relations—idempotence, absorption, conditional commutation, involution—predict unseen compositions?
- Where does the model’s algebra develop holes relative to program semantics?

Require held-out names, templates, histories, and compositions. That makes the object model-discovered rather than a lookup table.

### How C should enter

Only after the behavioral quotient predicts held-out compositions should C begin. Use causal interchange, not exploratory head archaeology:

1. Identify a candidate relay position.
2. Mask or remove access to the original operation tokens.
3. Transplant a donor state from one behaviorally defined class.
4. Require the recipient’s **full future-response signature** to follow the donor class.
5. Compare against random, position-matched, and norm-matched donors.

Layer-range localization can follow a successful interchange result. Head localization before that would tell us where a scalar bias travels, not what mathematics the model inhabits.

It must beat cheap lexical predictors and unrestricted surface baselines. If it fails—as the current evidence strongly predicts—close SVB and preserve the depth-stable scalar bias as a clean negative result.

The axiom that native mathematics exists should determine where we keep searching; it must not lower the evidence threshold for calling a scalar regularity an algebra.

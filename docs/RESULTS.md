# Results and current evidence

The existing results were consolidated on 22 October 2026. That consolidation used retained records. New software verification is dated below. MEASURED means an executed source-reported observation unless independently checked evidence is explicitly identified. TARGET, HYPOTHESIS, ESTIMATE, diagnostic and NOT_RUN are separate categories. The full optional-memory multimodal latent reasoner is a TARGET. Navigation is a supporting SLICE; source-byte identity does not establish semantic support, completeness, calibrated absence or useful latent computation. Design closure is not runtime qualification or launch authority.

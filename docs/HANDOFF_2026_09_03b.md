### 2. Settling mechanism characterized via suffix probes

Series of quick probes on Qwen3 revealing:

**Settling is a one-shot consolidation trigger, not processing time.**
- Double comment (+11.8%) worse than single (+13.0%)
- Bare newline only +2.5%, doesn't scale with depth

**Inertness gradient:** Docstrings (+17.5%) > Python `#` comments (+13.0%) >
`assert True` (+9.3%) > `pass` (+6.3%) > `\n` (+2.5%) > `import os` (-0.3%) >
`print()` (-15.4%). Code introducing new state hurts.

**Python-specific:** C++ `//` only +2.9% (integer division in Python). The model
responds to Python structural markers learned during pretraining.

**Docstring format contains attention:** Same correct text gives +16% in docstring,
-13% in comment (when mentioning variable name). Triple-quote boundary appears to
prevent variable reference from participating in attention competition.

**Depth loss is recoverable:** Optimal suffix (scope reminder docstring) gives
+21.6% at d4, reaching σ=0.940 — higher than raw d2 (0.897).

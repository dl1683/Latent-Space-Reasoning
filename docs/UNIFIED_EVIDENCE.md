# Unified evidence and construction constraints

Updated 2026-10-13. This is a source-grounded synthesis, **not a new proof review,
experiment, novelty adjudication or efficiency result**. Original records and their
corrections remain authoritative at their scopes. Imported working-tree hashes are
in [the manifest](../heritage/IMPORT_MANIFEST.json); complete custody is described in
[ASSETS.md](ASSETS.md).

The program asks what an inhabitant of a learned computational space must preserve
to identify, move, remember, revise and predict. The source collections supply
different objects: parameter memories, activation/KV states, matrix operators and
resource-constrained machines. A transfer between them is a hypothesis.

## What studying the programs together changes

These are worked deductions and construction hypotheses, not a composite result.
Each joins declared objects rather than assuming that parameter memories, activation
states, matrix descriptors and borrowed-state machines obey the same laws.

### Current understanding and remembered history have different identities

**Source premise:** CR-10's overwrite absorption removes a replaced write's causal
residue from every permitted future observation. **Conditional deduction:** a full
version-preserving memory cannot generally satisfy that law for historical queries.
Start from identical empty histories. `write(A,1); write(A,2)` and `write(A,2)` have
the same latest value; asking whether A previously held 1 separates their histories.
The source theorem can describe a declared current-view projection only when its
queries factor through that projection and every admitted current-view action obeys
`pi_cur(T_a X)=t_a(pi_cur(X))`; the projected writes must satisfy the original laws.
Excluding direct historical queries alone is insufficient: an action that restores
an earlier value can make a later current answer distinguish the histories. History-
sensitive actions need retained history or a separately declared, priced recovery/
refinement boundary. [Overwrite laws (line 318)](../theory/CONTINUATION_REFINEMENT.md).

A conventional realization retains immutable events, a latest-value index and
dependency-versioned derived answers. Revising A changes current consequences that
depend on A; historical queries still use the earlier event. A hypothetical branch
has its own version and never becomes an observation merely because it was simulated.
It need not replay the whole transcript. A learned carrier may implement these
operations differently, but must declare the same evidence, history and branch access.

**Open construction:** learn a cheaper current-action interface while keeping
history recoverable. The first separating trace is a late rule, a premise correction,
an affected consequence, an unrelated consequence and an earlier-version query.
Retrieving the earlier fact alone does not establish computing its new consequence;
forgetting it in a current view does not establish erasing it from all resources.

### A sufficient answer state may be insufficient for the next operation

**Source premises:** horizon equivalence induces an action from the next-horizon
quotient to the present-horizon quotient, not automatically a closed action on one
fixed summary; P2 reduced encoder-target defect without admitted selective continued
behavior. The existing branch engine still expands the state into a synthetic prefix,
runs the backbone for updates/readout, and recompresses. [Horizon law (line 70)](../theory/CONTINUATION_REFINEMENT.md),
[P2 result (line 93)](../experiments/EXPERIMENTS.md), [actual transition (line 154)](../experiments/cloud/lsr_jobs/branch.py).

**Derived choice:** change addressing, the update/reader interface, retained positions,
the representation or evidence access before treating an interface failure as a width
diagnosis. Separately identify storage, retrieval, computed consequences and causal
latent use. A good decoder and a lexical intervention do not jointly supply a portable
reasoning engine. A new engine must identify the recurring backbone work it replaces.

The allocation theory gives a second constraint: its specified quadratic objective
can attain its optimum by dropping low-weight features and keeping a flat surviving
spectrum. **Training hypothesis:** explicitly include declared rare/late future
distinctions, operations and corrections when they matter, rather than hope average
reconstruction preserves them. This is not a theorem about every neural loss, nor a
requirement of perfect recall. [Exact objective and optimum (line 102)](../theory/HD_POWER_LAW_ALLOCATION.md).

### Legal gradients, legal learning moves and runtime memory are different

**Source premise:** the Genome interventions act on parameters, optimizer buffers,
supervision and maintenance. The learning transition therefore includes those states;
it is not just a map of the supplied gradient. A gradient perpendicular to room vector
`u=(1,2)` can be `g=(2,-1)`, but coordinatewise `sign(g)=(1,-1)` has `u·sign(g)=-1`.
This elementary counterexample explains a possible geometry violation; it does not
report an observed failed e347 arm. [Actual optimizer paths (line 561)](../heritage/neural-dissection/lab/e347_optimizer_cross.py).

**Derived construction obligation:** inspect realized parameter displacement and
retained behavior, with matched effective motion, before assigning the mechanism to
buffer separation or gradient projection. Distinguish formation/adaptation memory,
state between runtime actions, and evidence retained for recovery. No theorem transfers
between those lifetimes solely because each is called memory.

Saved baselines, stored targets and maintenance controllers also belong in retained
resources. Measure behavior between maintenance events, not only after them. An
equally exposed conventional controller receives the same targets, history and budget.
[Saved-baseline undo (line 965)](../heritage/neural-dissection/lab/e299_embalming.py),
[phase-dependent correction (line 116)](../heritage/neural-dissection/THE_LAWS_V3.md).

### Exact representation growth and useful approximation can coexist

**Source premises:** fixed descriptor families can grow under composition; the GIRS
family simultaneously has an exact-width obstruction and cheap approximants. CRC's
approximate descriptor does not beat its already cheap retained exact word. Nonlinear
closed families also escape an unrestricted linear-algebra-only closure claim.
[GIRS contrast (line 77)](../heritage/matrix-native-math/research/GIRS_EXPLICIT_APPROXIMATION_V1.md),
[CRC costs (line 7)](../heritage/matrix-native-math/research/CRC_APPROXIMATION_V1_DISPOSITION.md),
[nonlinear family (line 56)](../heritage/matrix-native-math/research/NONLINEAR_COMPOSITION_SCOPE_V1.md).

**Conditional bridge to continued computation:** if a transition is L-Lipschitz on
an invariant declared domain and an approximate step adds error at most ε, then
`e_H ≤ L^H e_0 + ε·sum(L^j, j=0..H−1)`. An L_R-Lipschitz readout has error at most
`L_R e_H`; a threshold decision needs adequate margin as well. These elementary
assumptions must cover both trajectories and actual conversion/rounding errors.
They must be earned for the destination. One-step matrix-norm accuracy alone
does not supply them, and near-cancelling outputs can have poor relative accuracy.
[Source output/horizon exclusions (line 139)](../heritage/matrix-native-math/research/GIRS_EXPLICIT_APPROXIMATION_V1.md).

**Open construction:** retain cheap factors, switch representations or use a priced
defect/reopening route when the requested consequence permits it. A descriptor that
only bounds residual uncertainty need not reconstruct the missing residual direction.
Certificate, conversion, precision and fallback costs may defeat the intended benefit.
Independent questions about composition, interaction and recognition remain valuable
even before any neural implementation or specialist-beating engine exists.

A literal descriptor-to-layer bridge must also preserve the operator class:
`decode(compose(d2,d1))x = decode(d2)decode(d1)x` at the declared accuracy. An
unsupported sum, activation, normalization or input-dependent attention changes that
claim. In the source's three-block example, `Z''=aZ'+XY'+Zc'` already exposes arbitrary
rectangular multiplication when X and Y' are unrestricted. Cheap descriptor labels,
small radical depth or a commutative quotient do not pay for that interaction.
This is a reduction/control, not a superquadratic lower bound.
[Interaction construction (line 168)](../heritage/matrix-native-math/research/REPRESENTATION_FRONTIER_V2.md).

### Reusable knowledge and reusable computation need separate attribution

**Source premise:** teacher-provided labels improved a recipient head over fixed
features after teacher withdrawal; the fully labeled control showed adequate recipient
readout capacity. **Derived limit:** withdrawal demonstrates this bounded teaching
result, not transfer of the teacher's algorithm or backbone representation.
[Local precursor and controls (line 6245)](../theory/CUMULATIVE_CAPABILITY_ACQUISITION.md).

For a new layer operation, identify whether the resource supplies labels/facts,
exported distinctions, a callable computation or a preserved transformation. Compare
an equally exposed learner, a competent direct receiver and the original continuation.
Connected donor use is allowed and charged; removal is required only for a claimed
standalone assimilation. Neither geometric alignment nor successful teaching alone
identifies reusable computation.

The acquisition source adds a joint-use constraint: pairwise compatible ports need
not admit one consistent joint system, and compatible overlap marginals need not
identify a newly requested joint relationship. **Ecosystem hypothesis:** adaptation
can add a useful operation and obtain the necessary coupling information while
retaining old and joint uses at accounted cost. Unresolved coupling should remain
conditional rather than be supplied by confident decoding.
[Compatibility and coupling examples (line 2269)](../theory/CUMULATIVE_CAPABILITY_ACQUISITION.md).

### Restoration laws help specify moves without becoming neural theorems

The lease model specifies what an operation may borrow, which state must be restored,
its legal alphabet and observable output. Its function-class and word-cost questions
are different. **Worked transfer obligation:** a memory action may use scratch state
that must return, alter a designated persistent register, and preserve unrelated
registers. Intentional revision is outside a promise to restore the entire owner.
An ordinary implementation can save the permitted scratch/register state, execute
the same action and restore only the declared borrowed part; saved copies and control
work remain charged and must be permitted on both sides. If the contract forbids an
extra writable register or owner copy, charging a copy does not make it legal: the
original lease machine's ordinary comparator executes the same legal reversible
word without adding one. [Literal machine and promises (line 21)](../heritage/computation-models/ROUNDTABLE/work/codex/r16_THEORY.md),
[later classification (line 15)](../heritage/computation-models/ROUNDTABLE/work/droid/r19_REVIEW.md).

**Open mathematics:** identify operation laws, capability classes or resource tradeoffs
under a changed primitive/restoration contract. Applying the same words to a learned
continuous state supplies no finite-group classification or physical-energy theorem.
An equally resourced ordinary realization is a comparator and possible component,
not a verdict against independent mathematical or architectural progress.

## Reopening a failed approach

Name the original contract, failure and changed premise. Establish the cheapest
adequate remedy and a positive control before a costly new run. Reopening is useful
when it tests a different interface, operation, substrate or resource regime—not
when the same failed construction is given a larger sweep under the unified name.

For every bridge, record: source object; destination object; map; preserved operation;
premises; missing control; falsifier; full cost. Those obligations prevent the shared
vocabulary from being mistaken for evidence.

## Study Design

- Type: filtered_replication
- Tasks: 120 (80 same-family + 40 broader-domain)
- Arms: 5
- Primary endpoint: `true_clause_filtered > task_aware_generic`

### Arms

- **anchor**: best non-packet LLaDA response
- **fixed_generic**: count-matched boilerplate clauses (same pool as confirmatory)
- **task_aware_generic**: LLM-generated from task text only (frozen prompt)
- **true_clause_unfiltered**: raw pipeline clause output
- **true_clause_filtered**: post-defect-filter clause output

### GO Criteria

- Statistical: p < 0.05 on primary endpoint
- Practical: filtered wins >= 60%
- Error gate: unique harmful errors <= 5% of N
- Judge agreement: >= 2/3 model families show same direction

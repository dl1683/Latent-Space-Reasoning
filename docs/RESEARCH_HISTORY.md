The recurring breakpoint vocabulary remains useful:

1. Presence is not causation.
2. A single site is not the distributed state.
3. Vector distance is not semantic/behavioral distance.
4. Fixed coordinate dimension is not fixed operational structure.
5. Vector composition is not computational composition.
6. Observation is not the state itself.
7. A snapshot is not a computation trajectory.
8. Coordinate tools can impose the structure they discover.
9. Metric closeness can be blind to later composition.

These are constraints from particular experiments, not universal impossibility
theorems. Read the [registry](../theory/BREAKPOINT_REGISTRY.md) and later corrections
before extending their scope.

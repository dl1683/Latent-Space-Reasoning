# Failure patterns retained

This ledger summarizes historical evidence; compiling it did not run an experiment.

The fixed goal remains one multimodal model that encodes the whole corpus once into the space in which it reasons, with memory optional in the same call. The following failures constrain particular recipes and instruments; they do not close that goal. Reused-block recurrence and continuous hidden-state feedback remain distinct reasoning candidates. Neither has an admitted useful matched comparison.

This is a saved-source synthesis of all **125 historical F-IDs**, not a new audit, model run or semantic regrade. F-IDs remain stable. “Superseded” means a narrower repair exists; the original failure stays failed. Missing, blocked and censored outcomes remain UNKNOWN/NOT_RUN, not zero. Full entries and raw provenance must remain recoverable from the historical source records; the table is the working read-before-proposing surface.

## Decisions carried forward

1. **Central object:** one useful retained-state consequence/revision with a competent equally exposed conventional comparator; keep recurrence and feedback distinct. Receiver perfection on arbitrary tasks is not required, but the selected operation's positive control is.
2. **Supporting access:** preserve the service repairs and ordinary source-span delivery as qualified DEV candidates. Measure complete work and paired quality losses against ordinary CLI and dense retrieval. Do not start10M or broad confirmation on the strength of these screens.
3. **Acquisition/absence:** independent fresh relation and missing-premise tests, with risk and supported recall together. Authenticity, coverage, authority, entailment and calibrated absence remain separate claims.
4. **Numerical reuse:** retain conditional transport/certification opportunities; test conditioning/interactions and setup-inclusive break-even before adopting a new carrier.

Proposals are not run authorization. Execution is paused as recorded in README and RESULTS. Rank1 reached the three-round unsuccessful-repair cap; a new finite authorization and resource reconciliation are required.

**Snapshot mutability, 24 November 2026.** A static review of the feedback candidate found that read-only NumPy arrays still allowed callers to change array metadata and thereby alter the shapes seen by descendant states. The reproducers became regression fixtures. Public access now returns independent view headers over immutable bytes, installed maps own their array headers, and ordinary feedback-kernel reassignment is refused. The same defect was found and covered in the recurrent field when adding affine revisions. Verify this boundary whenever retained numerical state is exposed or reused across versions.

**Feature-moment collisions, 24 November 2026.** The [linear feedback fixtures](../experiments/memory/test_linear_feedback.py) expose two collisions. Opposite two-coordinate bindings over the same distinct keys yield identical unary moments. A selected conjunction feature recovers that constructed distinction. When two rows share a key, replacing opposing payloads with neutral values leaves the count, masses and first moments equal, including with pair features. Separate positive and negative payload columns recover the constructed marginal distinction. Conditioning a full-payload summary on one selected sign recovers the causal association in a two-step fixture. The partition still merges distinctions that share its retained moments, including evidence identities. Retain collision-relevant source distinctions when testing a learned or multiresolution successor.

**Source index publication, 24 November 2026.** Review found a failure in a design with one live source index per worker. An interruption after a durable event and a local row write could leave the source index ahead of the worker's moment snapshot. A retry could then subtract the replacement instead of the original row, while retained moment bounds still pass. The [journal implementation](../experiments/memory/feedback_journal.py) uses one transactional source index and replays the checked before and after rows from each event. The regression fixtures check interrupted acknowledgment and rollback of both records.

**Fixed-mixture repair with a validation guard, 24 November 2026.** In a [numerical fixture](../experiments/memory/test_feedback_workspace.py) the working probes and a validation guard all read the same observation mixture. The shared value-map edit could not satisfy the different working targets. The tested signed conditional edit fit those targets but changed the output on the guard's opposing state. A one-sided gate repaired that fixture and a full-span case with a positive threshold. A single gate that must remain inactive at every protected point still fails for targets within their convex hull, and an active-side guard rejected a fitted one-sided term. Finite separator search may also miss feasible gates.

**Duplicate operator search, 24 November 2026.** Independent rounds started on the same revision can enumerate the same deterministic candidates. The publication fence protects the journal and still permits wasted synthesis and replay. One coordinated round assigns distinct candidates to its local threads, and a journal plan can cover disjoint assignments across processes under a single publisher. Separate coordinators can still duplicate each other's work. A source revision can invalidate computations already in flight.

**Coordinator acknowledgment loss, 25 November 2026.** A coordinator could exit after appending a winning edit and leave the caller with a stale plan and no record of which attempt won. A refusal could also lose its continuation offset across restart. The queue now stores accepted decisions with the journal append and records refusals against the original tip. Fixtures inject a failed receipt write and an exit after commit. Reopening recovers the recorded decision and can continue a refusal on the same tip. [Queue fixtures](../experiments/memory/test_feedback_repair_queue.py)

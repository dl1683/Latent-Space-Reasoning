# Round 2: proposed joint pre-registration

**Verdict:** Continue. Make causal, selectable branch capacity the flagship. Use the frozen-model test as a cheap instrument check, not as the admission gate. A bounded fine-tuned 0.6B test is the gate. Defer cross-model transfer. This is a proposed common specification, not a claim that Codex has signed it.

*So what:* If one hidden state can preserve several possible solutions, update them, and answer a question chosen afterward, we can measure a useful form of latent reasoning rather than merely decode several guesses.

## 1. Frozen decisions

- **Capacity experiment:** Use one Qwen3-1.7B backbone with effective state widths **64, 256, 1024**. Train three seeds on the same curriculum, randomly exposing each width during training. Use one shared encoder, recurrence, and decoder; apply fixed, seed-specific nested rank masks to the 1024-dimensional state. Normalize state energy across masks. Thus width changes without changing the backbone, training examples, or latent-step budget. Report independently trained width adapters only as diagnostics.
- **Capacity definition:** For each width, capacity is the largest \(k\in\{1,2,4,8,16,32,64\}\) attaining **at least 90% accuracy per randomly selected branch** on locked examples. Report joint correctness separately. Do not interpret a floor, a ceiling at 64, or a failed single-branch control as a capacity measurement.
- **Numerical prediction:** If measured state participation ratio increases approximately fourfold between adjacent widths, the quadratic absolute-interference bridge predicts **2× capacity**; preregister **1.5–2.7×** for each such comparison. Across 64→1024, the nominal prediction is **4×**, conditional on approximately 16× participation ratio. A well-powered, non-censored capacity ratio outside the band when participation ratio is approximately fourfold **refutes this operational bridge**, not the repository’s quadratic random-feature theorem. Unstable participation ratio, a floor/ceiling, or failed mechanism merely fails to test the bridge. The theorem predicts expected interference for its specified readout; it does not prove reasoning capacity.

## 2. Flagship implementation and controls

Generate \(k\) independently sampled, labelled **layered directed graphs**, each with a source, four two-node layers, a sink, and 16 possible forward edges. Encode each graph by its 16 edge bits. Balance reachable and unreachable outcomes by rejection sampling, without revealing answers. Hold out graph compositions and edge-update pairs, not just labels. After the graphs are encoded, supply **two edge-toggle instructions**, one at each subsequent latent step; each toggles the named edge in *every* graph. Only then sample the **late selector** \(j\in[1,k]\). The answer is whether graph \(j\)’s sink is reachable after both toggles, scored by an exact graph algorithm. Do not expose the selector during encoding.

In torch/HuggingFace, prefill Qwen3-1.7B on the graph prompt and read its final residual state through a trainable 1024-dimensional bottleneck. **Discard the prompt and its entire KV cache.** For each update, start a fresh forward context containing only the projected state token and that update instruction; compress its final residual back into the masked state. Discard that context and cache too. For answering, start another fresh context containing only the final projected state and the late selector, and score the first `yes`/`no` token. No graph text, earlier update text, prior KV, external branch table, or independently solved candidates may enter the continuation. Check cache lengths and tensor paths, not merely the intended API behavior.

Compare zero, one, and two real updates with equal-FLOP sham updates; state-zeroed, shuffled, self-patched, and identity-plus-shared-displacement controls; a memory-only adapter; independent per-graph states at their **\(k\)-fold** cost; and matched text scratchpads and learned pause tokens. Construct paired prompts differing in only one graph. Patching their final states must change answers for that graph without degrading unchanged graphs; self-patching must restore the effect. A probe that can read graph bits but cannot carry out the two updates establishes storage, **not** the flagship claim. Participation ratio and fourth moments are diagnostics; the claim-bearing quantity is which future questions remain answerable after selective intervention. Using covariance or orthogonality as the verdict would repeat the project’s \(R^n\) trap.

**Flagship predictions:** single-branch accuracy ≥90%; at least four branches pass selective tests (targeted effect ≥20 percentage points, collateral effect ≤5 points, restoration ≥80% of induced loss); two updates retain that selectivity; and held-out exact-answer accuracy exceeds the strongest equal-FLOP control by ≥8 points, with a positive problem-paired 95% interval and the same direction across three seeds. Give mechanism, utility, and scaling **separate verdicts**. Kill escalation if the fine-tuned proximal gate fails after one bounded repair, if only retrieval survives, if caches or recomputation explain the result, or if equal-compute controls absorb the gain.

# Archive Index (Do Not Start Here)

This page is for readers who are already familiar with the promoted evidence path.
If you are new, use [NAVIGATION.md](NAVIGATION.md) instead.

## Archive Zones

- `docs/reports/diffusion/`  
  Generated diffusion reports. Current V10/V11/V12 and confirmatory-study
  reports are linked from NAVIGATION.md; the rest is historical, for deep
  reproduction and forensic review, not onboarding.

- `archive/tesla_session/`
  Deep internal session notes. Keep for context history, usually not needed for
  active claims.

- `meditations/question_*.md`  
  Private question-first exploration notes. These guide future questions and
  maintenance, but they are not the promoted evidence surface.

- `eval_results/`  
  Generated task outputs and raw artifacts. Prefer links to these through
  evidence surfaces (`DIFFUSION_GROUND_TRUTH_INDEX.md`, `CLAIM_EVIDENCE_MAP.md`)
  instead of browsing directly.

- `experiments/*.py` scripts  
  The experiment corpus is large; prefer entry points listed in
  [README.md](../README.md) and [DIFFUSION_READER_GUIDE.md](DIFFUSION_READER_GUIDE.md).

- `archive/legacy_notes/`
  Historical narrative snapshots moved out of the repository root:
  [GOALS.md](../archive/legacy_notes/GOALS.md),
  [ARTICLE_UPDATE.md](../archive/legacy_notes/ARTICLE_UPDATE.md),
  [RESEARCH_BRIEF.md](../archive/legacy_notes/RESEARCH_BRIEF.md), and
  [README.md](../archive/legacy_notes/README.md).

## How to use archived folders

1. Confirm the statement is already in a promoted claim/artifact surface.
2. Open the related archive file only if you need exact call arguments,
   historical baselines, or raw reproduction details.
3. For current status, use:
   - [CLAIM_EVIDENCE_MAP.md](../CLAIM_EVIDENCE_MAP.md)
   - [DIFFUSION_GROUND_TRUTH_INDEX.md](../DIFFUSION_GROUND_TRUTH_INDEX.md)
   - [DIFFUSION_THEORY_CLAIM_LEDGER.md](DIFFUSION_THEORY_CLAIM_LEDGER.md)
   - [DIFFUSION_PUBLIC_BENCHMARK.md](../DIFFUSION_PUBLIC_BENCHMARK.md)

# Question Recursion?

## What Must A Question Prove Before It Guides Work?

- What decision would this question change if it were sharpened?
- What evidence would this question force into view?
- What replication would this question demand before becoming trusted?
- What forecast would this question make possible?
- What incentive would distort this question if it became important?
- What institution would be needed to preserve this question after the current agent leaves?

## What Question Does Each Question Need Before Evidence?

- What would count as evidence for this question without becoming an answer too soon?
- What would count as evidence against this question without killing useful uncertainty too soon?
- What source would be independent enough to change the question?
- What source would be too correlated to count as confirmation?
- What hidden denominator would make the evidence interpretable?
- What missing negative result would make the evidence look stronger than it is?
- What provenance would need to travel with the evidence so the question remains auditable?

## What Question Does Each Question Need Before Replication?

- What would it mean to replicate a question?
- What would remain invariant if the same question were asked by another agent?
- What would change if the same question were asked against a fresh benchmark slice?
- What would change if the same question were asked from another repo?
- What would change if the same question were asked after a failed build?
- What part of the question is method-dependent?
- What part of the question is object-dependent?
- What replication failure would expose that the original question was only local wording?

## What Question Does Each Question Need Before Forecasting?

- What future observation would this question predict should become easier to interpret?
- What probability would a calibrated forecaster assign to this question becoming architecture-relevant?
- What market would price whether this question survives the next evidence update?
- What conditional forecast would compare building now against asking longer?
- What forecast horizon matches the question's cognitive light cone?
- What would make the forecast thin, manipulable, or overconfident?
- What liquidity of evidence would be required before the forecast deserves trust?

## What Question Does Each Question Need Before Institutional Memory?

- What record would let a future agent know why this question existed?
- What procedure would update this question without erasing its provenance?
- What rule would prevent the question from being promoted merely because it is elegant?
- What rule would prevent the question from being forgotten merely because it is inconvenient?
- What role would monitor the question for drift?
- What archive would preserve failed answers as inputs to better questions?
- What institutional memory would survive if the markdown file disappeared?

## What Question Does Each Question Need Before Incentives?

- What reward would make agents ask shallow versions of this question?
- What citation, benchmark, or commit incentive would make this question easier to game?
- What prestige signal would make this question sound deeper than it is?
- What cleanup pressure would delete the uncertainty this question protects?
- What shipping pressure would force this question to become a premature answer?
- What market incentive would price consensus while ignoring source quality?
- What institutional incentive would reward novelty while punishing replication?

## What Question Does Each Question Need Before Search?

- What search space does this question open?
- What search space does this question close?
- What stepping stone does this question preserve?
- What deceptive gradient does this question avoid?
- What behavior-space coordinate does this question add to the archive?
- What novelty signal would show that a new question is not merely a paraphrase?
- What selection rule would keep the question because it improves future search?
- What selection rule would retire the question because it only consumes attention?

## What Question Does Each Question Need Before Maintenance?

- What is the staleness rate of this question?
- What is the drift detector for this question?
- What is the repair pathway for this question?
- What is the retirement pathway for this question?
- What is the replay schedule for this question?
- What is the failure mode where maintaining this question becomes worse than forgetting it?
- What meta-question detects whether the maintenance process is preserving inquiry or preserving clutter?

## What Question Does Each Question Need Before Compression?

- What can be safely compressed out of this question?
- What cannot be compressed without losing the causal handle?
- What cannot be compressed without losing the falsifier?
- What cannot be compressed without losing provenance?
- What cannot be compressed without losing the reason the question mattered?
- What summary would make this question easier to read but easier to misuse?
- What minimum form preserves enough structure for a future agent to ask the next deeper question?

## What Question Does Each Question Need Before Boundary Drawing?

- What system boundary does this question assume?
- What would move inside the boundary if the question were taken seriously?
- What would move outside the boundary if the question were narrowed?
- What hidden actor is already participating in the reasoning system?
- What hidden artifact is already functioning as memory?
- What hidden institution is already acting as verifier?
- What boundary error would make the question blame the model for a system failure?

## What Question Does Each Question Need Before Grounding?

- What contact with reality would anchor this question?
- What causal intervention would make this question less symbolic?
- What verifier-visible delta would ground this question without overbuilding?
- What replay would ground this question across time?
- What failed prediction would ground this question more honestly than a fluent explanation?
- What embodied, operational, or institutional consequence would show that the question touched the world?
- What grounding would be impossible from text alone?

## What Question Does Each Question Need Before It Becomes Public?

- What public claim would this question be tempted to support?
- What public claim would this question not yet support?
- What caveat must remain attached to the question?
- What evidence boundary must be visible beside the question?
- What uncertainty would a reader need in order not to overbelieve the question?
- What simplification would make the question more persuasive but less true?
- What should remain internal until replication, forecasting, or orthogonal verification exists?

## What Question Does Each Question Need Before The Next Agent?

- What should the next agent ask before modifying this question?
- What should the next agent ask before deleting this question?
- What should the next agent ask before building from this question?
- What should the next agent ask before citing this question as progress?
- What should the next agent ask before turning this question into a task?
- What should the next agent ask before treating this meditation as complete?
- What question would make the next agent slower in exactly the way that produces better work?

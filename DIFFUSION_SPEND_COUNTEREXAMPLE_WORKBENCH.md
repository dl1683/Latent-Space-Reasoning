## Reading

The v8 result makes the controller split concrete. Post-repair promotion is stable on the generated candidates, but pre-repair spend is not separable by a small conjunction of source quality, prompt gap, denoise phase, and trajectory-relative delta. The next architecture should therefore use counterexample-driven active data collection or a richer value model before attempting another live spend gate.

# Troubleshooting Guide

This guide helps you resolve common issues when running experiments and using the Latent Space Reasoning Engine.

> ⚠️ **Note:** Scorer numbers (`latent_score`, `confidence`) are internal search guidance only. Always evaluate decoded outputs directly for quality decisions — see [CLAUDE.md](CLAUDE.md) for detailed evaluation guidelines.

## Quick Diagnostics

Check your environment with the built-in options:

```bash
# Show available models and system info
latent-reason models

# Basic CLI check
latent-reason run "Hello, world?" --encoder Qwen/Qwen3-0.6B --verbosity minimal

# Or use Python directly to verify PyTorch
python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}'); print(f'Device count: {torch.cuda.device_count() if torch.cuda.is_available() else 0}')"
```

## Common Issues

### 1. Installation Problems

**Error: `ModuleNotFoundError: No module named 'latent_reasoning'`**
```bash
# Install the package in editable mode
pip install -e .

# Or with dev dependencies (tests, linting)
pip install -e ".[dev]"
```

**Error: `No module named 'torch'`**
```bash
# Install PyTorch
pip install torch torchvision torchaudio

# For CUDA support
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
```

### 2. GPU/Memory Issues

**Error: `CUDA out of memory`**
```bash
# Use a smaller model
latent-reason run "your query" --encoder Qwen/Qwen3-0.6B

# Or use CPU (slower but works on any machine)
# Edit config to set device: "cpu"
```

**Error: `torch.cuda.OutOfMemoryError` during experiments**
```bash
# Reduce batch size or model size in experiment scripts
python experiments/run_latent_sensitivity.py --model Qwen/Qwen3-1.7B
```

### 3. Experiment Script Issues

**Problem: Experiment scripts fail with no results**
```bash
# Check that all dependencies are installed
pip install -e ".[all]"

# Verify the experiment run queue for correct usage
cat experiments/RUN_QUEUE.md

# Check if the harness has proper arguments
python experiments/harness.py --help
```

**Problem: Reproducing paper results**
The paper experiments use specific random seeds and model configurations:
- Results are stored in `experiments/*_results.json` files
- Plots generated by `experiments/plot_*.py` scripts
- Full experiment ledger in `experiments/ledger.jsonl`

### 4. Code Quality Checks

**Linting or type check failures before submitting a PR**
```bash
# Run all quality checks
make lint        # ruff linting
make format      # ruff formatting + auto-fix
make typecheck   # mypy type checking

# Run tests (no GPU required for unit tests)
make test-fast   # unit tests only (skip GPU-dependent integration tests)
make test        # all tests (including integration, needs GPU)
```

### 5. Model Loading Issues

**Error: `OSError: Can't load tokenizer for 'Qwen/Qwen3-4B'`**
- Ensure you have internet access for downloading HuggingFace models
- Try a smaller model: `Qwen/Qwen3-0.6B` (2GB VRAM minimum)
- Or use a cached local model path

**Error: `FileNotFoundError: checkpoints/latent_scorer/final_model.pt`**
- The trained scorer checkpoint may not be included in the repo
- Run with just heuristic scoring: adjust config to use heuristic scorer only
- Or train your own scorer using the training pipeline

### 6. Output Issues

**Problem: Garbled or missing characters in output**
```bash
# Save output to JSON for reliable inspection
latent-reason run "your query" --verbosity silent > output.json

# Or use the Python API directly
python -c "
from latent_reasoning import reason
result = reason('your query', verbosity='silent')
print(result.plan)
"
```

**Problem: Results differ from paper**
The paper reports specific configurations. Minor variations are expected due to:
- Floating point nondeterminism across GPU architectures
- Different model quantization levels
- Random seed initialization

## Hardware Recommendations

### Limited GPU (2-4GB VRAM)
```bash
latent-reason run "query" --encoder Qwen/Qwen3-0.6B
```

### Mid-range GPU (4-8GB VRAM)
```bash
latent-reason run "query" --encoder Qwen/Qwen3-1.7B
```

### High-end GPU (8GB+ VRAM)
```bash
latent-reason run "query" --encoder Qwen/Qwen3-4B
```

### CPU Only
```bash
latent-reason run "query" --encoder Qwen/Qwen3-0.6B --chains 2 --generations 5
# Or use the Python API with CPU configuration
```

## Getting Help

1. **Check experiment docs**: `experiments/EXPERIMENTS.md` and `experiments/RUN_QUEUE.md`
2. **Read the research brief**: `RESEARCH_BRIEF.md` for full technical context
3. **Run the comparison**: Use `latent-reason compare "query"` to see evolution impact
4. **Check existing issues**: Search open and closed issues for similar problems

## Reporting Issues

Please include:
- Python version (`python --version`)
- PyTorch version (`python -c "import torch; print(torch.__version__)"`)
- GPU info (`python -c "import torch; print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"`)
- The exact command or script you ran
- The full error message (use `--verbosity debug` for detailed logs)
